# 公式速查

## 报表恒等式

- [[会计恒等式]]：资产 = 负债 + 股东权益。
- [[股东权益]]：股东权益 = 资产 - 负债。

## 利润表

- [[毛利率]] = 毛利 / 营业收入 = (营业收入 - 营业成本) / 营业收入。
- [[净利润率]] = 净利润 / 营业收入。

## 营运能力

- [[总资产周转率]] = 营业收入 / 平均总资产。
- 应收账款周转率 = 营业收入 / 平均应收账款。
- 存货周转率 = 营业成本 / 平均存货。
- 周转天数 = 365 / 周转率。

## 投资回报

- [[总资产报酬率]] = 净利润 / 平均总资产。
- [[净资产收益率]] = 净利润 / 平均股东权益。
- 效率 x 效益 = 总资产周转率 x 净利润率 = 总资产报酬率。

## 偿债能力

- [[流动比率]] = 流动资产 / 流动负债。
- [[速动比率]] = (流动资产 - 存货) / 流动负债。
- [[息税前收益]] = 净利润 + 所得税 + 利息费用。
- [[利息保障倍数]] = EBIT / 利息费用。
- [[资产负债率]] = 总负债 / 总资产。

## 好公司判断

- [[投资资本回报率]] 要高于 [[加权平均资本成本]]，企业才是在创造价值。
- 当行业风险高、资产质量可疑时，优先看 [[现金流量表]]；当资产质量可靠、经营风险可控时，[[利润表]]更能反映收益能力。

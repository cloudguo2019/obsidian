# Xttrade 接口速查

## 初始化接口 -> [[交易接口与回调实战]]

| 接口 | 作用 |
| --- | --- |
| `XtQuantTrader(path, session_id)` | 创建交易 API 实例 |
| `register_callback(callback)` | 注册回调对象 |
| `start()` | 启动交易线程 |
| `connect()` | 连接 MiniQMT |
| `run_forever()` | 阻塞线程，持续接收主推 |
| `stop()` | 停止接口 |

## 交易接口 -> [[交易接口与回调实战]]

| 接口                                    | 作用        |
| ------------------------------------- | --------- |
| `order_stock(...)`                    | 股票同步下单    |
| `order_stock_async(...)`              | 股票异步下单    |
| `cancel_order_stock(...)`             | 通过订单号撤单   |
| `cancel_order_stock_async(...)`       | 异步撤单      |
| `cancel_order_stock_sysid(...)`       | 通过柜台合同号撤单 |
| `sync_transaction_from_external(...)` | 外部成交导入    |

## 查询接口 -> [[交易接口与回调实战]]

| 接口 | 作用 |
| --- | --- |
| `query_stock_asset(account)` | 查询资产 |
| `query_stock_orders(account)` | 查询当日委托列表 |
| `query_stock_trades(account)` | 查询当日成交列表 |
| `query_stock_positions(account)` | 查询持仓列表 |
| `query_position_statistics(account)` | 查询期货持仓统计 |
| `query_credit_detail(account)` | 信用资产查询 |

## 回调接口 -> [[交易接口与回调实战]]

| 回调 | 触发含义 |
| --- | --- |
| `on_disconnected()` | 连接断开 |
| `on_account_status(data)` | 账户状态变更 |
| `on_stock_order(data)` | 委托状态变更 |
| `on_stock_trade(data)` | 成交变更 |
| `on_order_error(data)` | 下单失败 |
| `on_cancel_error(data)` | 撤单失败 |
| `on_order_stock_async_response(data)` | 异步下单回报 |

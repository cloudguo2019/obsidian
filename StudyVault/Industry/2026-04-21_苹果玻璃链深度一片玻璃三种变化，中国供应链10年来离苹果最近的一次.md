# 苹果玻璃链深度：一片玻璃三种变化，中国供应链10年来离苹果最近的一次

> iPhone 17的Ceramic Shield 2、iPhone Fold的UTG、Vision Pro的曲面盖板——三种玻璃在三款重量级产品上同时切换，中国供应链在UTG这一代首次触及上游配方层突破。蓝思科技三张牌叠加，凯盛科技30微米UTG追平康宁，但真正的分水岭要看苹果何时愿意分出一部分上游订单。

---

## 一、核心反差：中国供应链十年最接近苹果的一次

过去10年，中国消费电子供应链早已吃掉苹果60%的组装订单，但上游玻璃配方这一层，一直被康宁和肖特卡得死死的。苹果一年卖约2.2亿部iPhone，单部手机用到4到6片玻璃（前屏、后盖、摄像头镜片、Face ID玻璃），年采购金额约60到80亿美元，占整个消费电子玻璃市场一半左右。

这条链分上下两层：

- **上游**：原片和配方——康宁、肖特、AGC三家垄断高端市场；
- **下游**：切割、磨边、抛光、镀膜、热弯和盖板加工——蓝思和伯恩两家中国巨无霸，占据全球一半以上份额。

中国人长期在下游吃肉，上游配方和原片被美日德卡住。但这次苹果换玻璃，第一次在上游给国产公司留了一条缝。

---

## 二、三种玻璃，三重格局

### （一）Ceramic Shield 2：康宁独享，中国赚加工钱

去年9月，iPhone 17全系搭载Ceramic Shield 2。苹果官网披露：抗划伤能力提升3倍，7层抗反射涂层，纳米晶体结构密度更高。最值得关注的是iPhone 17 Air——5.6毫米厚度的史上最薄iPhone，首次把Ceramic Shield 1用在了后盖上，抗摔裂能力提升4倍。

Ceramic Shield的本质是康宁的微晶玻璃配方：在玻璃基体里嵌入纳米级陶瓷晶体，保留玻璃透光性，获得陶瓷硬度。这个配方是苹果从2017年开始，通过先进制造基金累计投资近5亿美元，与康宁联合研发的成果。

今年8月，苹果宣布第二笔投资25亿美元，扩产康宁肯塔基Harrodsburg工厂，工程师和制造人员增加50%，目标是让iPhone和Apple Watch盖板玻璃100%美国产。苹果10年内给康宁累计投资近30亿美元，换来的是**独家配方、独家产能、独家时间差**。Ceramic Shield 2的配方目前只有康宁能做，国产替代暂无可能。

中国人赚的是加工的钱。康宁把原片切成薄片运到中国，蓝思在湘潭、泰州的工厂里切割、磨边、抛光、镀膜、热弯，变成成品盖板再送回苹果。这一套工艺附加值约为原片的2.3倍。

> 值得注意：iPhone 17 Air的盖板玻璃独家供应商不是蓝思，而是伯恩。双龙头格局未变，蓝思并非一家独吞。

### （二）UTG：iPhone Fold的最大变量，蓝思吃肉，凯盛求突破

今年秋天最大的变量：iPhone Fold。据郭明錤和The Information 4月最新口径——iPhone Fold原计划2026年9月发布，生产微延迟1到2个月，秋季档不变，起售价2000至2500美元。首年出货目标800到1000万台，第二年翻倍至2500万台。

折叠屏手机最难做的不是屏幕，是盖板。传统玻璃太脆折不了，塑料薄膜柔性好但划伤快、手感差。2020年以后出现第三条路：UTG超薄柔性玻璃，厚度30到100微米，既耐折又足够硬。UTG全球目前仅三家能做：康宁、肖特和凯盛科技（30微米）。三星最新一代折叠屏用肖特，华为三折叠独家用凯盛。

iPhone Fold用谁？郭明錤给出答案：蓝思承接约70%的UTG加工订单，但UTG原材料苹果选的仍是康宁。UTG工艺要求中心折叠区可弯折减薄，其他区域保持厚度增强抗冲击性——这是蓝思的强项。而30微米原片，全球仅康宁一家能稳定供应大厂。凯盛虽能做30微米，但目前主要大客户是华为和国内六家手机厂，不是苹果。

按UTG成本是普通手机玻璃2到4倍计算，蓝思单部手机的玻璃加工收入可翻至3到4倍。

凯盛目前处于二线待上车的位置。它的UTG二期项目已在2025年建成，年产能1500万片，投资10.2亿元。国内六大手机厂均在使用，但进苹果链目前仅有媒体推测，无公司公告——这是非常关键的区别。

但反过来说，康宁的Gorilla Glass垄断上游15年，这次在UTG细分类目，首次出现了一家能做30微米的中国公司。这是十年来最接近的一次上游突破。

### （三）Vision Pro/ Vision Air：未来时，可能不用玻璃了

蓝思在一代Vision Pro上已拿到关键位置：3D曲面夹层盖板——头显正面那块能看到眼睛的曲面玻璃。2024年库克访问蓝思湘潭工厂时，周群飞现场展示过。这是中国公司第一次在苹果AR/VR产品上供应核心显示件。

但最反直觉的部分在这里。彭博社马克·古尔曼最新口径：Vision Pro 2在2026年内发布，仅将芯片升级到M5，其他设计基本不变，玻璃工艺无变更传闻。真正有变化的是2027年的Vision Air——郭明錤预测重量减轻40%，价格降低50%，做到约1500美元。做法是用**塑料替代玻璃**，用镁合金替代铝合金。苹果下一代头显可能不用玻璃了。

这对蓝思的影响：短期利空（Vision Air玻璃用量减少），但中期是利好——头显要真正起量，只有价格降一半才有可能。蓝思在Vision Pro上赚的是1200美元单机里约80美元的玻璃钱，而Vision Air一旦起量，哪怕单机玻璃钱降到30美元，总销量翻10倍仍然更优。

## 三、重点公司分析

### 蓝思科技（300433）

| 指标 | 数据 |
|------|------|
| 2025年营收 | 744亿元 |
| 净利 | 40亿元 |
| 毛利率 | 16% |
| 苹果营收占比（2024） | 49.45%（约346亿元，5年前超60%） |
| 汽车业务 | 64亿元 |
| VR+穿戴 | 39亿元 |

中国消费电子玻璃加工最大企业。苹果营收占比下降不是因为苹果量变少，而是蓝思主动分散业务。产能分三块：国内湘潭和泰州为主基地，越南二园区达80万平米，泰国新厂即将投产，墨西哥工厂配套特斯拉。海外收入占比已升至25%，是应对地缘风险的关键布局。

本次机会在于三张牌同时叠加：
1. Ceramic Shield 2加工订单
2. iPhone Fold约70%的UTG加工
3. Vision Pro曲面盖板独供

三张牌中任意一张单独看都不小，叠加起来是过去5年里最密集的一次催化。最大风险：苹果依赖度接近一半，苹果销量一动，蓝思利润就抖一下。

### 凯盛科技（600552）

| 指标 | 数据 |
|------|------|
| 2025年营收 | 59亿元 |
| 净利 | 1.29亿元 |
| 规模对比 | 约为蓝思的1/12 |
| 控股股东 | 中国建材集团（央企） |
| UTG二期产能 | 1500万片/年，投资10.2亿元 |

凯盛是中建材体系里做特种玻璃的核心平台。UTG业务归在显示材料板块，2025年营收46亿，同比增长31%。重要客户：华为三折叠和卷轴屏独家供应，国内六大厂全覆盖。

关键矛盾：2025年增收20%，净利反而下降8%，增收不增利。原因是UTG二期产线刚投产，良率仍在爬坡期，前期投入摊销吃掉利润。这恰恰说明凯盛正从研发产能走向规模盈利的临界点——过了这个点，每多出一片UTG利润弹性非常大；过不去，则又是卷在价格战里的玻璃公司。进苹果链尚无公司公告，仅有媒体推测。

### 康宁（Corning）

| 指标 | 数据 |
|------|------|
| 2025年营收 | 164亿美元（同比+13%） |
| 特殊材料分部（含Gorilla Glass） | 22亿美元，净利3.67亿美元（+41%） |
| 有效专利 | 1.1万件 |

国产替代10年未攻破康宁的原因：不是做不出玻璃，是做不出"配方+良率"。Gorilla Glass从第一代到Victus 2，每一代都是新配方。Ceramic Shield的微晶玻璃配方由康宁和苹果联合研发，这种配方护城河没有20-30年沉淀做不出来。

但UTG是例外。UTG的核心不是配方，是把玻璃做薄的工艺问题。切到30微米还不碎，中国和日德的差距没有那么大。这也是为什么凯盛突破UTG与想做Ceramic Shield 2是完全不同的两件事。

## 四、行业走向判断

大概率路径：
- iPhone Fold 2026年9月如期发布（概率60%）
- Ceramic Shield 2继续迭代（100%已落地）
- Vision Pro 2年内发布，仅升级芯片（经反复确认）
- Vision Air 2027年发布，低价头显才是更大拐点
- 上下游联动四层：玻璃原料 → 玻璃加工 → OLED面板贴合 → 终端整机。京东方、维信诺、TCL华星在折叠屏OLED上同步受益；大族激光、华工科技在UTG皮秒激光切割设备上是隐性受益方；车载大屏、AR/VR曲面盖板是第二曲线

## 风险提示

> [!warning]
> - 苹果对供应链的订单分配具有高度不确定性，任何单一产品的出货量不及预期都将直接影响加工企业利润
> - 蓝思科技苹果营收占比接近50%，存在单一客户过度依赖风险，若苹果销量波动或主动分散供应商，将造成重大冲击
> - 凯盛科技UTG二期良率爬坡存在不确定性，若不能稳定突破90%，从增收不增利转向规模盈利的拐点可能推迟
> - 地缘政治风险：苹果推动盖板玻璃100%美国产，可能逐步压缩中国加工企业的份额
> - Vision Air采用塑料替代玻璃的方案如落地，将对玻璃加工企业AR/VR业务构成结构性利空
> - 折叠屏手机市场整体增速若低于预期，UTG产能可能面临过剩

## 三个结论

1. **Ceramic Shield 2是康宁的护城河，中国赚加工钱。** 苹果10年投康宁近30亿美元，独家配方+产能+时间差，国产替代暂无可能，蓝思伯恩赚的是2.3倍附加值的加工利润。
2. **UTG是中国供应链十年最接近苹果上游的一次突破。** 凯盛30微米UTG追平康宁，但进苹果链的节点尚未确认。蓝思拿70%加工订单是确定性最高的一环，单机玻璃收入可翻4倍。
3. **Vision Air可能不用玻璃，短期利空但长期利好。** 塑料替代玻璃会降低单机价值，但头显价格降至1500美元才可能起量，总量逻辑远大于单机逻辑。

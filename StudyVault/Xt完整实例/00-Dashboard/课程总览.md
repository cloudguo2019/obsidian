# Xt完整实例学习总览

> [!summary]
> 本学习包来自 ThinkTrader 原生 API 的“完整实例”网页，重点不是逐行背代码，而是把示例拆成可复用的实盘工作流：行情准备、连接管理、交易回调、下单风控和异常恢复。

## 学习路线

1. [[来源与主题映射]]：先确认网页示例覆盖哪些主题。
2. [[接口速查]]：建立 `xtdata`、`xtdatacenter`、`XtQuantTrader` 的接口索引。
3. [[Xt行情完整实例]]：掌握行情补数、订阅、连接服务器、复权和衍生品映射。
4. [[Xt交易完整实例]]：掌握交易连接、回调、实盘订阅、重连、信用还款和回调撤单。
5. [[Xt完整实例练习题]]：用场景题检查是否能把代码流程迁移到自己的策略。
6. [[易错点]]：复盘最容易导致空数据、无回调、重复下单和连接资源耗尽的点。

## Weak Areas

- [ ] 分不清本地历史数据和实时订阅数据的关系 -> [[Xt行情完整实例]] -> [[易错点]]

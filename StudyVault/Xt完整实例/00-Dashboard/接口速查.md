# Xt完整实例接口速查

## 行情准备 -> [[Xt行情完整实例]]

| API                                                                          | 作用            | 记忆点                             |
| ---------------------------------------------------------------------------- | ------------- | ------------------------------- |
| `xtdata.download_history_data(code, period, start_time, incrementally=True)` | 下载本地历史行情      | 下载接口本身不返回行情，后续还要用查询接口取数         |
| `xtdata.download_financial_data(code_list)`                                  | 下载财务数据        | 示例里和行情补数一起做准备                   |
| `xtdata.download_sector_data()`                                              | 下载板块数据        | 后续可用 `get_stock_list_in_sector` |
| `xtdata.get_market_data_ex(fields, code_list, period, count)`                | 读取本地/订阅拼接后的行情 | 订阅后会拼接历史与实时                     |
| `xtdata.get_market_data(fields, code_list, period, start_time)`              | 一次性取行情        | 适合明确字段和起始时间                     |

## 行情订阅与阻塞 -> [[Xt行情完整实例]]

| API | 作用 | 记忆点 |
| --- | --- | --- |
| `xtdata.subscribe_quote(code, period, count, callback=None)` | 订阅标的行情 | 有 callback 时由异步回调触发 |
| `xtdata.get_full_tick([code])` | 获取全推 tick | 对手价和最新价常从这里取 |
| `xtdata.run()` | 阻塞主线程 | 否则脚本执行到末尾会退出，回调无法持续 |

## 行情服务器连接 -> [[Xt行情完整实例]]

| API | 作用 | 记忆点 |
| --- | --- | --- |
| `xtdc.set_token(token)` | 设置行情服务 token | 需先于 `xtdc.init()` |
| `xtdc.set_allow_optmize_address(addr_list)` | 限定优选连接池 | 常用于 VIP 服务器范围 |
| `xtdc.set_kline_mirror_enabled(True)` | 开启 K 线全推 | 用于获取全市场实时 K 线 |
| `xtdc.set_kline_mirror_markets(['SH','SZ','BJ'])` | 设置全推市场 | 避免不必要市场初始化 |
| `xtdc.set_init_markets(init_markets)` | 设置初始化市场 | 和连接耗时、可用数据范围相关 |
| `xtdc.listen(port=58621)` | 监听本地端口 | 返回端口后给 `xtdata.connect` |
| `xtdata.connect(port=port)` | 连接行情中心 | `xtdc.listen` 和 `xtdata.connect` 是配套动作 |
| `xtdata.QuoteServer(info).connect()` | 连接指定行情服务器 | 配合 `watch_quote_server_status` 判断状态 |
| `xtdata.watch_quote_server_status(func)` | 注册连接状态回调 | 用于确认指定站点是否连接成功 |

## 交易连接 -> [[Xt交易完整实例]]

| API                                     | 作用       | 记忆点                  |
| --------------------------------------- | -------- | -------------------- |
| `XtQuantTrader(path, session_id)`       | 创建交易连接对象 | `path` 按券商端/投研端不同而不同 |
| `xt_trader.register_callback(callback)` | 注册交易回调   | 要在启动交易线程和接收主推前配置好    |
| `xt_trader.start()`                     | 启动交易线程   | 先 start，再 connect    |
| `xt_trader.connect()`                   | 建立交易连接   | 返回 `0` 表示成功          |
| `xt_trader.subscribe(account)`          | 订阅账户主推   | 不订阅就收不到该账户维度回调       |
| `xt_trader.run_forever()`               | 阻塞交易主线程  | 实盘脚本保持运行             |

## 交易查询与下单 -> [[Xt交易完整实例]]

| API | 作用 | 记忆点 |
| --- | --- | --- |
| `query_stock_asset(account)` | 查询资金资产 | 示例用 `m_dCash` 计算可用资金 |
| `query_stock_positions(account)` | 查询持仓 | 示例构造总持仓和可用持仓字典 |
| `order_stock_async(...)` | 异步下单 | 结果需要看异步响应、委托回报、成交回报 |
| `order_stock(...)` | 同步下单/特殊业务 | 信用还款示例使用同步方式 |
| `cancel_order_stock_sysid_async(account, market, order_sysid)` | 按柜台合同编号异步撤单 | 常在 `on_stock_order` 中拿到 `order_sysid` 后触发 |

## 回调事件 -> [[Xt交易完整实例]]

| 回调 | 触发时机 | 学习重点 |
| --- | --- | --- |
| `on_disconnected` | 交易连接断开 | 设置状态，触发有限重连 |
| `on_stock_order` | 委托状态变化 | 可读订单状态、已成数量、柜台合同编号 |
| `on_stock_trade` | 成交变化 | 确认成交价格、数量、方向 |
| `on_order_error` | 报单失败 | 记录错误信息和委托备注 |
| `on_cancel_error` | 撤单失败 | 记录撤单错误 |
| `on_order_stock_async_response` | 异步下单响应 | 只代表请求响应，不等于成交 |
| `on_cancel_order_stock_async_response` | 异步撤单响应 | 只代表撤单请求响应，不等于最终状态 |
| `on_account_status` | 账户状态变化 | 连接与账户可用性监控 |

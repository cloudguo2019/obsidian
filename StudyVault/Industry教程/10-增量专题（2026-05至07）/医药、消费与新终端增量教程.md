# 医药、消费与新终端增量教程

#industry/healthcare #industry/consumer #industry/tutorial #industry/incremental

## Overview Table

| 主题 | 增长叙事 | 真正瓶颈 | 验证指标 |
|---|---|---|---|
| 脑机接口 | 医疗刚需与政策支持 | 电极、采集芯片、手术机器人、临床 | 证书、手术量、真实收入 |
| 昭衍新药 | 行业订单回暖 | 主业毛利与猴价会计 | 扣除公允价值后的利润 |
| 凯莱英 | 减肥药与 CDMO 新周期 | 订单转化、产能利用率 | 在手订单、收入、现金流 |
| AI 眼镜 | 出货快速增长 | 光学、芯片、微显示 | 各环节毛利与量产 |
| 跨境电商 | 中国品牌出海 | 关税、渠道、库存、品牌 | 海外收入、复购、现金周转 |

## 脑机接口：医学器械不是普通消费电子

| 路线 | 特征 | 商业化难点 |
|---|---|---|
| 非侵入式 | 风险低、信号弱 | 精度和应用深度 |
| 半侵入式 | 信号与风险折中 | 手术和长期稳定性 |
| 侵入式 | 信号强 | 安全、伦理、临床和监管 |

判断上市公司是否“真脑机”：

- 是否有核心产品而非参股概念；
- 是否取得医疗器械证；
- 是否有医院、病例和收费；
- 收入占比是否可见。

> [!warning] 例外
> 全球首证是行业里程碑，但不自动映射到所有 A 股概念股。技术路线、股权关系和产品收入必须逐项核对。

## 昭衍新药：利润质量比利润增速重要

昭衍的特殊点是生物资产按公允价值计量。猴价上涨可以产生未实现的账面收益，导致净利率远高于主业毛利率。

| 指标 | 看什么 |
|---|---|
| 安评收入与毛利 | 主业是否修复 |
| 在手/新签订单 | 未来 6-12 个月收入 |
| 生物资产公允价值 | 会计波动来源 |
| 扣除重估后的利润 | 真实经营结果 |
| 现金流 | 利润是否变成现金 |

## 凯莱英：从新冠大单切换到减肥药

CDMO 的核心不是单一热门药，而是项目漏斗：

```text
临床前 → 临床一期 → 二期 → 三期 → 商业化
项目数量逐级减少，单项目收入逐级增加
```

| 检查 | 目的 |
|---|---|
| 在手订单与新签 | 看需求 |
| 大客户占比 | 看集中风险 |
| 产能利用率 | 看折旧压力 |
| 小分子/多肽等结构 | 看增长引擎 |
| 经营现金流 | 看订单兑现 |

## AI 眼镜：出货量与利润池分离

| 环节 | 特征 | 利润判断 |
|---|---|---|
| 整机组装 | 规模大、替代性较高 | 毛利较薄 |
| 光学/光波导 | 技术和良率壁垒 | 可收“过路费” |
| 声学 | 份额与器件能力 | 中等毛利 |
| 主控芯片 | 高价值量 | 毛利高但周期波动 |
| 微显示 | 有屏 AR 的瓶颈 | 成本与良率决定放量 |

无屏 AI 眼镜和有屏 AR 是不同产品周期。短期出货可能由无屏款驱动，不能把更远期的有屏市场提前全部计入。

## 跨境电商：政策冲击是一场商业模式压力测试

| 模式 | 免税取消后的表现 | 护城河 |
|---|---|---|
| 低价铺货 | 税费直接吞利润 | 弱 |
| 精品模式 | 可优化产品与供应链 | 中 |
| 品牌出海 | 有一定提价与复购 | 强 |
| 海外仓 | 改善时效 | 库存和资金占用高 |
| 独立站 | 掌握用户 | 获客成本高 |

品牌型公司并非天然安全，还要验证营销费用、库存周转、区域收入和经营现金流。

## 财报质量的统一检查表

| 看起来很好 | 必须追问 |
|---|---|
| 净利暴增 | 公允价值、处置、并表、低基数占多少 |
| 订单增加 | 何时确认收入、需不需要扩产 |
| 出货翻倍 | 哪个环节拿走毛利 |
| 主题首证 | 上市公司有没有产品和收入 |
| 海外增长 | 关税、渠道、库存与现金流 |

## Exam/Test Patterns

| 场景/关键词 | 应答框架 |
|---|---|
| “全球首证” | 查证书主体、路线、病例和收入 |
| “净利增长 479%” | 还原扣非和公允价值 |
| “减肥药受益” | 查项目阶段、订单与产能利用率 |
| “AI 眼镜爆发” | 分组装、光学、芯片、显示 |
| “品牌出海” | 查复购、营销费、库存和现金流 |

# 资源材料与制造业利润池增量教程

#industry/materials #industry/tutorial #industry/incremental

## Overview Table

| 利润来源 | 典型行业 | 护城河 | 最大风险 |
|---|---|---|---|
| 资源禀赋 | 金、铜、锡锑、重稀土、钨 | 矿权、品位、配额 | 商品价格下跌 |
| 加工费 | 铜铅冶炼、普钢、锡膏 | 规模、效率、客户 | 原料涨价与过剩 |
| 技术认证 | 航空碳纤维、特钢、碲化铋 | 配方、工艺、认证 | 放量慢 |
| 品牌/渠道 | 莱赛尔、消费材料 | 品牌溢价 | 国产扩产压价 |
| 生物工艺 | 合成生物制造 | 菌株、收率、规模 | 大宗价格战 |

## 三种定价权

```text
资源定价权：别人没有矿/配额
技术定价权：别人做不出稳定合格品
品牌定价权：客户愿意为同类产品多付钱

只有产能规模 → 通常不足以形成定价权
```

## 矿企与冶炼厂：同一金属，两种利润表

| 公司类型 | 收入 | 成本 | 涨价弹性 |
|---|---|---|---|
| 自有矿 | 金属价格 × 产量 | 采选成本 | 强 |
| 冶炼加工 | 原料价值 + 加工费 | 原料、能源、资金 | 弱，甚至受挤压 |
| 一体化 | 矿山 + 冶炼 | 内部对冲 | 中等，取决于自给率 |

中金黄金的核心是矿产金而非冶炼金；江西铜业和豫光金铅的高营收、低净利则体现加工模式。判断金属涨价受益，必须先算**自有矿产量与原料自给率**。

## 战略小金属：供给稀缺不等于公司阿尔法

| 金属 | 稀缺来源 | 公司层面仍需检查 |
|---|---|---|
| 重稀土（镝铽） | 资源集中、出口与配额 | 矿权、分离指标、磁材节省技术 |
| 钨 | 配额、资源集中、军工需求 | 库存、应收、刀具高端化 |
| 锑 | 供给收紧、光伏/阻燃需求 | 自有矿与冶炼占比 |
| 锡 | 资源约束、电子需求 | 产量与价格弹性 |
| 碲化铋 | 温控需求与小市场 | 真实收入、产能和客户认证 |

> [!warning] 例外
> 小市场容易被少量需求和资金放大。产品只占公司营收很小比例时，材料价格上涨未必显著改变整体利润。

## 高纯石英砂：下游切换决定公司命运

高纯石英砂曾高度依赖光伏石英坩埚需求，价格大跌后，企业分化来自矿源、纯度等级和能否切入半导体/光纤等高端市场。关键不是“砂价跌了多少”，而是：

- 高端矿源是否稳定；
- 产品能否进入半导体级认证；
- 光伏库存是否出清；
- 新用途收入是否足以覆盖旧业务下滑。

## 钢铁：普钢、特钢和铸管不是一个行业

| 类型 | 主要产品 | 赚钱逻辑 |
|---|---|---|
| 普钢 | 板材、长材 | 成本、区位、产品结构、供给出清 |
| 特钢 | 高温合金、轴承钢等 | 技术认证与高端占比 |
| 铸管 | 球墨铸铁管 | 水利需求、渠道、订单 |

中信特钢在行业下行中维持利润，反映高端产品结构；新兴铸管不应只按普钢估值；普钢九家分化说明吨钢利润、区位和出口结构比总产量更重要。

## 碳纤维：军品底盘与民品拖累并存

两篇光威复材文章共同给出一个框架：

| 业务 | 特征 | 关注点 |
|---|---|---|
| 军品长单 | 认证深、毛利较高、节奏受计划影响 | 交付与回款 |
| 大飞机材料 | 长周期增量 | C919/C929 认证和放量 |
| 商业航天 | 远期弹性 | 订单真实性 |
| 风电碳梁 | 规模大、价格竞争 | 毛利与客户集中 |

营收创新高但净利下降，常见原因是低毛利业务占比上升、价格下降和高毛利军品交付节奏变化。

## 莱赛尔：规模冠军悖论

| 环节 | 行业状态 | 利润逻辑 |
|---|---|---|
| 溶解浆 | 进口依赖、资源集中 | 上游稀缺 |
| 粘胶短纤 | 可扩产、同质化 | 价格战 |
| 粘胶长丝 | 新增产能受限 | 配额稀缺 |
| 莱赛尔 | 中国规模领先 | 过度扩产压低高端溢价 |
| 品牌端 | “天丝”等品牌 | 品牌与渠道溢价 |

## 生物制造：实验室收率不等于工厂利润

生物制造用菌株替代石化路线，商业化要跨过三关：

1. 菌株性能：收率、转化率、稳定性；
2. 工艺放大：从发酵罐到万吨装置；
3. 市场定价：产品不能迅速变成大宗价格战。

凯赛、华恒等案例说明，真正护城河是菌株 + 工艺 + 客户 + 规模的组合。

## Exam/Test Patterns

| 场景/关键词 | 应答框架 |
|---|---|
| “金属价格暴涨” | 查自有矿量、加工费、库存与现金流 |
| “全球产能第一” | 查毛利、品牌和上游资源 |
| “高端材料认证” | 查批量收入与复购 |
| “特钢龙头” | 分产品等级与终端认证 |
| “生物制造降本” | 查收率、工厂利用率和产品价格 |

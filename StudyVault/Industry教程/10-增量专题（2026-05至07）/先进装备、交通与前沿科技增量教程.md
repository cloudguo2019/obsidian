## 高端装备的五级证据梯

```text
概念布局 → 样品 → 认证 → 订单 → 批量交付与回款
```

| 级别 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 概念布局 | 公司知道方向 | 没有收入 |
| 样品 | 技术可做 | 不代表稳定 |
| 认证 | 获得准入 | 不代表大订单 |
| 订单 | 有需求 | 不代表当期利润 |
| 交付回款 | 商业闭环 | 仍需检查毛利和复购 |

## LNG 船：总份额与高端份额分开看

中国造船总份额高，不等于 LNG 船等高附加值船型同样领先。船舶 v2 的更新重点是：

- USTR 301 等政策会改变订单地区分布与成本；
- “零订单”可能受统计窗口、船东选择和交付周期影响；
- 破冰订单的关键不是数量，而是货舱系统、主机和后续复制能力。

## Robotaxi：硬件降价只是第一关

| 变量 | 对单车经济的影响 |
|---|---|
| 激光雷达/域控/线控底盘 | 降低初始购置成本 |
| 日订单与运营小时 | 摊薄车辆固定成本 |
| 空驶率 | 决定有效收入 |
| 远程接管与安全员 | 可能吞掉“无人”节省 |
| 保险、维护、事故率 | 决定长期成本 |
| 监管开放范围 | 决定可运营市场 |

> [!important] 单车经济
> `单车经营现金流 = 订单收入 - 能源 - 维护 - 保险 - 远程运营 - 折旧`。只有持续为正，Robotaxi 才从技术演示变成生意。

## eVTOL：适航证比融资额更值钱

| 门槛 | 为什么重要 |
|---|---|
| 型号合格证 | 证明设计符合安全标准 |
| 生产许可证 | 证明工厂能稳定复制 |
| 适航证 | 单架航空器可投入运行 |
| 运营资质 | 决定能否收费飞行 |

短期更容易商业化的场景是文旅、应急和固定航线，不应直接按“城市空中出租车全面普及”估值。

## 核聚变设备链：项目节点比市场空间重要

| 环节 | 作用 | 主要约束 |
|---|---|---|
| 超导磁体 | 约束等离子体 | 带材、低温、磁体制造 |
| 第一壁/包层 | 承受中子和热负荷 | 材料寿命与氚增殖 |
| 偏滤器 | 排热与排杂 | 极端热流密度 |
| 真空室/杜瓦 | 维持真空和低温 | 大型精密制造 |
| 加热系统 | 点燃并维持等离子体 | 回旋管与电源 |

聚变项目周期长，收入按设备招标和里程碑确认；“2030 目标”不是年度利润预测。

## 机器人、机床与航空材料：主题收入要落到报表

| 案例 | 表面叙事 | 教程检查 |
|---|---|---|
| 双环传动 | 机器人减速器 | 机器人子公司收入、盈利与客户 |
| 创世纪 | 苹果链、人形机器人 | 扣非、现金流、实际订单 |
| 汇川技术 | 工控龙头 + 人形机器人 | 工控底盘与机器人期权分开估值 |
| 应流股份 | 核电、燃机、低空 | 高端铸件认证与订单兑现 |
| 中航高科 | C919 千架订单 | 材料交付节奏、军品波动与毛利 |

> [!warning] 例外
> 一次性诉讼、资产减值或低基数会让归母净利失真。创世纪应同时看扣非和经营现金流；中航高科应区分长期订单与当期交付节奏。

## 量子计算：技术进步与商业估值分开

| 技术指标 | 为什么重要 |
|---|---|
| 物理量子比特 | 规模基础 |
| 纠错率 | 决定能否组成逻辑量子比特 |
| 相干时间 | 决定可执行计算深度 |
| 门保真度 | 决定错误积累速度 |
| 可用逻辑比特 | 最接近真实计算能力 |

营收很小的公司可以参与真实技术突破，但估值必须按商业任务、客户付费与融资消耗检验。

## Exam/Test Patterns

| 场景/关键词 | 应答框架 |
|---|---|
| “全球份额第一” | 分总量份额与高端产品份额 |
| “拿到适航证” | 分型号、生产、单机适航和运营资质 |
| “订单充足” | 查交付、收入确认、毛利和回款 |
| “机器人概念” | 查该业务实际收入占比 |
| “量子突破” | 查逻辑量子比特与可重复任务 |

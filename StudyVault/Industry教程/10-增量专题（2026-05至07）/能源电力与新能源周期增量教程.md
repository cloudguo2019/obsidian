# 能源电力与新能源周期增量教程

#industry/power-energy #industry/tutorial #industry/incremental

## Overview Table

| 行业 | 收入驱动 | 成本驱动 | 关键制度/周期 |
|---|---|---|---|
| 火电 | 电量、电价、容量电价 | 煤价 | 电力市场化与保供 |
| 煤炭 | 长协价、现货价、销量 | 采矿成本 | 长协与产能周期 |
| 核电 | 装机、利用小时、上网电价 | 折旧、财务费用 | 审批、建设周期 |
| 石油上游 | 油气产量与油价 | 桶油成本 | 地缘与资本开支 |
| 炼化 | 产品价差 | 原油、折旧、利息 | 产能出清 |
| 光伏硅料 | 硅价与销量 | 现金/完全成本 | 过剩与反内卷 |
| 隔膜 | 出货与单价 | 产能利用率 | 价格拐点 |

## 周期行业的利润桥

```text
商品/电价变化
    ↓
实际售价格（长协会削弱弹性）
    ↓
单位价差 = 售价 - 现金成本
    ↓
固定成本、折旧、利息
    ↓
报表利润
    ↓
库存、应收、资本开支
    ↓
自由现金流与分红
```

## 火电：从“卖电量”到“电量 + 容量”

容量电价为火电机组的可用容量和保供价值付费，使部分固定成本得到补偿。火电盈利可简化为：

`火电利润 ≈ 电量 ×（上网电价 - 单位燃料成本）+ 容量补偿 - 折旧与财务费用`

| 公司/类型 | 应看什么 |
|---|---|
| 纯火电弹性 | 煤价、市场电价、容量收入 |
| 火电 + 绿电 | 两块业务分别看电价与利用率 |
| 华能国际案例 | 绿电入市后电价下行可能拖累整体 |

> [!warning] 例外
> “新能源装机增长”不保证绿电利润增长。若市场化电价下跌、弃电或折旧上升，新增装机也可能增收不增利。

## 煤炭：长协把周期股变成半个收租生意

| 模式 | 上涨期 | 下跌期 |
|---|---|---|
| 高长协占比 | 涨价弹性弱 | 收入更稳 |
| 高现货占比 | 弹性强 | 回撤大 |
| 煤电运一体化 | 内部对冲 | 资本更重 |

分析煤企要把“现货价格上涨”与“公司综合售价”分开，继续检查成本、产量、分红和矿井寿命。

## 核电：确定性高，但兑现慢

核电的价值来自长寿命资产、较高利用小时和稳定现金流；风险来自建设期长、前期资本开支大、折旧与利息高。中国核电的“在建 19 台”是长期容量储备，不等于当年利润跃升。

| 观察信号 | 含义 |
|---|---|
| 新机组核准 | 长期项目储备 |
| 商运时间 | 收入开始确认 |
| 利用小时 | 资产效率 |
| 上网电价 | 单位收入 |
| 负债与财务费用 | 股东现金流约束 |

## 石油：上游与下游是两门相反的生意

| 环节 | 赚钱逻辑 | 关键指标 |
|---|---|---|
| 勘探开采 | 油价减桶油成本 | 产量、储量、完全成本 |
| 油服 | 资本开支转订单 | 在手订单、利用率、回款 |
| 炼油 | 炼油价差 | 开工率、库存 |
| PX/PTA/化纤 | 产品价差与供给 | PX-石脑油价差、PTA 加工费 |
| 烯烃 | 石油/乙烷/煤路线竞争 | 原料路线与产品价差 |

中海油的低完全成本说明上游的护城河是成本曲线；恒力、荣盛等炼化企业则要看一体化深度、负债和价差。营收规模不等于利润规模。

## 电网设备：标签纯度比行业热度重要

许继电气的特高压直流业务占比远低于“特高压龙头”给人的直觉。分析设备公司要做一张收入纯度表：

| 检查项 | 问题 |
|---|---|
| 主题业务占比 | 真正贡献多少营收/毛利 |
| 传统业务 | 是否价格战拖累 |
| 订单确认 | 高毛利订单何时交付 |
| 现金流 | 应收和垫资是否恶化 |

## 光伏与隔膜：反转必须跨过完全成本

| 行业 | 左侧信号 | 右侧确认 |
|---|---|---|
| 多晶硅 | 亏损收窄、减产 | 硅价站上完全成本且单季转盈 |
| 隔膜 | 龙头先扭亏、价格止跌 | 多家公司毛利和现金流改善 |

通威的现金成本回答“能不能继续生产”，完全成本回答“报表何时赚钱”。星源材质与恩捷股份的时间差提醒我们：同行反转可作先行信号，但不能替代本公司的财务确认。

## Exam/Test Patterns

| 场景/关键词 | 应答框架 |
|---|---|
| “煤价涨，煤企受益” | 先看长协比例与综合售价 |
| “火电夕阳行业” | 看容量电价、煤价与现金流 |
| “在建机组很多” | 看商运时点、折旧和利息 |
| “油价上涨” | 分上游、炼化和油服 |
| “反内卷” | 查实际减产、价格和完全成本 |

# 电力新能源与储能产业链教程

## 入门：电力行业看三件事

电力行业不是“发多少电”这么简单。研究电力和新能源，要同时看：

| 问题 | 含义 |
|---|---|
| 发得出来吗 | 光伏、风电、核电、火电、水电等电源建设 |
| 送得出去吗 | 特高压、配网、变压器、开关、继保、电力电子 |
| 用得稳定吗 | 储能、调峰、虚拟电厂、数据中心供电、负荷管理 |

AI 数据中心和新能源车同时提高用电需求，但新能源发电具有波动性，所以电网、储能和电力电子变成共同瓶颈。

## 产业链内部关系

```text
电源侧
  -> 风电/光伏/核电/火电/氢能
      -> 电网侧
          -> 特高压/变压器/开关/继保/电力电子
              -> 用户侧
                  -> 工业、居民、AIDC、充电桩
                      -> 储能/调峰/虚拟电厂
```

## 主要细分行业

| 细分 | 基础知识 | 利润池 | 代表公司 |
|---|---|---|---|
| 电网设备 | 电力从发电端到用户端，需要升压、输电、降压和保护 | 特高压、变压器、继保、配网自动化 | 国电南瑞、许继电气、平高电气、特变电工、四方股份 |
| 固态变压器/SST | 用电力电子替代传统铜铁变压器，适合高密度数据中心 | 效率提升、体积下降、直流供电 | 四方股份 |
| 储能 | 把电在低价/富余时存起来，高价/紧缺时释放 | 电芯、PCS、系统集成、温控 | 宁德时代、阳光电源、上能电气、科华数据、盛弘股份 |
| 光伏 | 硅料、硅片、电池片、组件、逆变器 | 周期下行时利润集中在成本领先者和逆变器 | 隆基绿能、通威股份、TCL中环、阳光电源、锦浪科技 |
| 海上风电 | 海风项目离岸更远，需要海缆和施工能力 | 海缆毛利高于风机 | 东方电缆、中天科技、亨通光电、明阳智能、金风科技 |
| 核电 | 高资本开支、长周期、强监管 | 设备资质、阀门、控制系统、运营资产 | 中国核电、中核科技、东方电气 |
| 氢能 | 绿氢需要电解槽，成本取决于电价和设备 | 电解槽、储运、应用场景 | 隆基氢能、阳光电源、华电重工、亿华通 |

## 储能：为什么出货翻倍也会亏

储能产业链可拆成：

| 环节 | 特点 | 公司 |
|---|---|---|
| 电芯 | 成本占比高，规模和电池技术重要 | 宁德时代、亿纬锂能、国轩高科 |
| PCS | 电池和电网之间的电力转换 | 阳光电源、上能电气、盛弘股份 |
| 系统集成 | 项目交付和方案整合 | 阳光电源、科华数据、南都电源 |
| 温控/消防 | 安全和效率必需 | 英维克、高澜股份、青鸟消防 |

行业容易亏的原因：

1. 系统集成门槛相对低，价格战激烈。
2. 电芯价格下行时，库存和订单报价错配。
3. 海外项目认证、渠道、质保要求更高。
4. 储能收益模型依赖电价机制，政策变化影响大。

## 同环节公司对比

| 环节 | 龙头 | 跟随者/同环节 | 差异点 |
|---|---|---|---|
| 电网自动化 | 国电南瑞 | 许继电气、四方股份、东方电子 | 南瑞综合最强；许继偏一次/二次设备；四方在继保和 SST 具特色 |
| 变压器/输变电 | 特变电工 | 中国西电、平高电气、保变电气 | 特变规模和海外强；平高偏开关；西电偏高压设备 |
| 储能逆变器/PCS | 阳光电源 | 上能电气、盛弘股份、科华数据 | 阳光全球渠道强；上能/盛弘弹性较高 |
| 电芯 | 宁德时代 | 亿纬锂能、国轩高科、鹏辉能源 | 宁德规模、客户、技术领先；二线厂看细分和海外 |
| 海缆 | 东方电缆 | 中天科技、亨通光电、宝胜股份 | 海缆资质、码头、交付能力是壁垒 |
| 核电设备 | 中核科技 | 江苏神通、东方电气、上海电气 | 核级阀门和资质决定进入门槛 |

## 关键观察信号

1. 电网投资是否从主网向配网、数字化、柔性化扩散。
2. AIDC 用电是否推动园区级变电站和 SST。
3. 储能是否从“强配”转向真实收益模型。
4. 海上风电招标是否恢复，海缆单价和交付节奏。
5. 核电审批、开工和设备订单是否延续。

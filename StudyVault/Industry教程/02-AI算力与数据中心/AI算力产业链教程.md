# AI算力产业链教程

## 入门：AI算力不是一块 GPU

AI 算力产业链可以理解为一个“训练和推理工厂”：

```text
大模型/智能体应用
  -> 算力需求和 Token 消耗
      -> GPU/AI芯片服务器
          -> 数据中心机房
              -> 光模块/PCB/液冷/供配电
                  -> 光器件、电子布、铜箔、特气、能源
```

原文里最重要的判断是：AI 应用越复杂，Token 消耗越高，算力需求越刚性。OpenCLE/智能体这类应用把“问答式 AI”变成“多步骤任务执行”，会放大算力消耗。

## 产业链内部关系

| 环节 | 作用 | 主要约束 | 代表公司 |
|---|---|---|---|
| 云服务/算力租赁 | 把 GPU 资源卖给模型和应用方 | 资金、卡源、运维、客户利用率 | 优刻得、青云科技、首都在线、润泽科技、数据港 |
| AI芯片 | 提供核心计算 | CUDA/CANN 生态、先进制程、HBM | 英伟达、华为昇腾、寒武纪 |
| 光模块 | 服务器之间高速互联 | 速率升级、客户认证、良率 | 中际旭创、新易盛、光迅科技、华工科技 |
| 光器件 | 光模块核心零部件 | 精密加工、客户覆盖 | 天孚通信 |
| PCB/CCL/铜箔/电子布 | 承载高速信号 | 高频高速材料、Low DK、良率 | 沪电股份、胜宏科技、生益科技、宏和科技、中国巨石、中材科技 |
| 液冷/温控 | 降低高密度机柜散热压力 | 数据中心验证、交付能力 | 英维克、申菱环境、高澜股份 |
| AIDC建设 | 机房、电力、暖通、运维 | 土地、电力指标、资本开支 | 润泽科技、奥飞数据、数据港 |
| 供配电 | 把电稳定送进机柜 | 变压器、UPS、SST、电网接入 | 四方股份、许继电气、特变电工 |

## 利润池在哪里

| 利润池 | 为什么可能赚钱 | 为什么也可能亏 |
|---|---|---|
| 光模块 | AI 集群互联刚需，速率从 400G 到 800G/1.6T 升级 | 客户集中，技术代际切换快 |
| 光器件 | 给多个光模块厂供货，是“卖铲人的卖铲人” | 如果下游降价，零部件也会被压价 |
| 液冷 | 机柜功率提升后成为刚需 | 项目制交付、竞争者增加 |
| 高端 PCB/材料 | AI 服务器要求高频高速材料 | 扩产后可能结构性过热 |
| 算力租赁 | 需求真实时现金流强 | 卡价高、折旧快、利用率不够会吞掉利润 |

## 同环节公司对比

| 环节 | 龙头/强势公司 | 同环节其他公司 | 差异点 |
|---|---|---|---|
| 光模块 | 中际旭创 | 新易盛、光迅科技、华工科技 | 中际份额和客户强；新易盛弹性强；光迅/华工带国产替代属性 |
| 光器件 | 天孚通信 | 太辰光、博创科技 | 天孚客户覆盖更广，受益于多家光模块厂扩张 |
| PCB | 沪电股份 | 胜宏科技、深南电路、生益电子 | 沪电更受益 AI 服务器高端板；胜宏弹性强；深南偏通信和封装基板 |
| CCL/材料 | 生益科技 | 华正新材、南亚新材 | 生益综合实力强，高端材料突破决定估值空间 |
| 电子布/玻纤 | 宏和科技 | 中国巨石、中材科技、光远新材 | 宏和更纯；巨石平台型；中材绑定高端客户；光远新材偏 Low DK 国产突破 |
| 温控 | 英维克 | 申菱环境、高澜股份 | 英维克全链条交付强；其他公司更偏细分场景 |
| 算力租赁/IDC | 润泽科技 | 优刻得、青云科技、首都在线、奥飞数据、数据港 | 润泽偏大型 AIDC；优刻得/青云更偏云服务弹性；首都在线海外节点突出 |

## 重点观察信号

1. GPU 集群建设是否继续扩张，尤其是推理需求是否接上训练需求。
2. 800G/1.6T 光模块出货节奏和客户认证。
3. 算力租赁公司的利用率、客户质量和折旧压力。
4. 数据中心电力指标、液冷渗透率和机柜功率密度。
5. 高端 PCB、Low DK 电子布是否出现扩产过热。

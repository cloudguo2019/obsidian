# 半导体与电子材料产业链教程

## 入门：半导体产业链分三层

```text
设计
  -> 制造
      -> 封测

制造和封测背后：
设备 + 材料 + 工艺 + 良率 + 客户认证
```

对非行业读者来说，最重要的是分清“芯片公司”和“给芯片制造供货的公司”。原文里的很多机会不在芯片设计，而在设备、材料、封装和高端电子材料。

## 产业链内部关系

| 环节 | 基础知识 | 代表公司 |
|---|---|---|
| 前道设备 | 晶圆制造所需设备，包括刻蚀、薄膜沉积、清洗、检测等 | 北方华创、中微公司、拓荆科技、盛美上海、华海清科、芯源微 |
| 半导体硅片 | 晶圆制造的基底材料 | 沪硅产业、TCL中环、立昂微 |
| 光刻胶 | 光刻工艺关键材料，难在配方、纯度和客户验证 | 南大光电、彤程新材、晶瑞电材、上海新阳 |
| 湿电子化学品/CMP | 清洗、蚀刻、抛光，纯度要求极高 | 江化微、晶瑞电材、安集科技、鼎龙股份 |
| 电子特气 | 刻蚀、沉积、掺杂等工艺用气体 | 华特气体、金宏气体、雅克科技、南大光电 |
| 先进封装 | CoWoS、Chiplet、HBM 相关封装能力 | 长电科技、通富微电、甬矽电子、华天科技 |
| PCB/CCL/电子布 | AI 服务器高频高速传输材料 | 沪电股份、生益科技、宏和科技、中国巨石、中材科技 |
| SiC | 新能源车、光伏、充电桩、高压电力电子 | 天岳先进、三安光电、斯达半导、士兰微、时代电气 |
| 存储 | NAND、DRAM 受周期和国产替代影响 | 长江存储、长鑫存储相关供应链 |

## 半导体材料的共性

| 共性 | 为什么重要 |
|---|---|
| 纯度高 | 一点杂质就会影响良率 |
| 认证慢 | 晶圆厂不会轻易换供应商 |
| 批量稳定比样品更难 | 实验室突破不等于商业化 |
| 客户粘性强 | 一旦导入，替换成本高 |
| 国产替代分层 | 低端导入和高端替代不是一回事 |

## 同环节公司对比

| 环节 | 龙头/代表 | 同环节公司 | 差异点 |
|---|---|---|---|
| 刻蚀/薄膜设备 | 北方华创、中微公司 | 拓荆科技、盛美上海、芯源微、华海清科 | 北方平台型；中微刻蚀强；拓荆薄膜；盛美清洗；华海 CMP 设备 |
| CMP材料 | 安集科技 | 鼎龙股份、江丰电子 | 安集抛光液突出；鼎龙向抛光垫和材料延伸 |
| 光刻胶 | 南大光电 | 彤程新材、晶瑞电材、上海新阳 | 南大在 ArF 推进；彤程整合平台；晶瑞/上海新阳偏材料体系 |
| 电子特气 | 华特气体 | 金宏气体、雅克科技、凯美特气、南大光电 | 华特半导体特气纯度和客户突出；金宏综合气体；雅克部分电子材料 |
| 先进封装 | 长电科技 | 通富微电、华天科技、甬矽电子 | 长电规模和客户强；通富 AMD 链突出；甬矽弹性较大 |
| PCB | 沪电股份 | 胜宏科技、深南电路、生益电子 | 沪电受益 AI 服务器；胜宏高弹性；深南通信和封装基板属性 |
| CCL | 生益科技 | 华正新材、南亚新材 | 生益综合实力强，高端材料突破是关键 |
| 功率半导体 | 斯达半导、士兰微 | 扬杰科技、时代电气、东微半导、新洁能 | 斯达 IGBT 模块，士兰 IDM 综合，时代电气高压场景 |
| SiC衬底/器件 | 天岳先进、三安光电 | 东尼电子、露笑科技、时代电气 | 衬底、外延、器件、模块不是同一层 |

## 分析重点：国产替代要问“替代哪一层”

| 替代层级 | 难度 | 例子 |
|---|---|---|
| 低端耗材替代 | 较低 | 部分清洗液、基础化学品 |
| 单点设备替代 | 中高 | 清洗、CMP、部分刻蚀 |
| 高端材料替代 | 高 | ArF 光刻胶、高端电子特气、Low DK 材料 |
| 生态替代 | 极高 | EDA、先进制程、CUDA 类生态 |

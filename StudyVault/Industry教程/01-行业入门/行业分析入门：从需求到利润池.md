# 行业分析入门：从需求到利润池

行业分析的第一课：不要一上来问“哪家公司最好”，先问“钱为什么会流进这个行业，又停在哪个环节”。

## 1. 需求不是利润

很多新手会把“行业有增长”直接等同于“公司会赚钱”。原文里反复出现相反案例：

| 行业 | 看起来的需求 | 真正的分化 |
|---|---|---|
| 光伏 | 装机长期增长 | 硅料暴跌、组件价格战，龙头也可能亏损 |
| 储能 | 出货翻倍 | 一半企业亏钱，系统集成环节价格战严重 |
| 正极材料 | 占电芯成本高 | 产能过剩时，成本占比高反而承压 |
| 玻纤 | 中国占全球产能高 | 粗纱平稳，Low DK 电子布因 AI 服务器爆发 |
| 维生素 | 中国掌握大产能 | VA/VE 与 VC/VB 剧本不同，龙头独享利润 |

> [!tip]
> 需求增长只是第一层。行业研究真正要找的是：需求增长之后，哪个环节供给最难扩、价格最容易涨、成本最容易控、客户最难替换。

## 2. 利润池来自四种瓶颈

| 瓶颈类型 | 判断方法 | 典型案例 |
|---|---|---|
| 资源瓶颈 | 矿权、配额、地理集中度 | 磷矿、钨、稀土、钴、铀 |
| 技术瓶颈 | 纯度、良率、认证、工艺步数 | 光刻胶、电子特气、Low DK 电子布、超导带材 |
| 产能瓶颈 | 扩产周期长、设备交付慢 | CoWoS、光模块、海缆、核电阀门 |
| 生态瓶颈 | 软件、客户绑定、系统集成 | CUDA、机器人控制器、伺服全栈、工业自动化 |

## 3. 一个行业的基本拆法

```text
终端需求
  -> 关键系统
      -> 核心部件
          -> 关键材料
              -> 上游资源/设备
```

以 AI 服务器为例：

```text
AI应用和大模型
  -> GPU服务器/数据中心
      -> 光模块/PCB/液冷/供电系统
          -> 光器件/铜箔/覆铜板/电子布/SiC器件
              -> 高纯材料/特气/电力设备/金属资源
```

这样拆完以后，才知道为什么 AI 不只利好软件，也会传导到光模块、PCB、玻纤、电网、核电、固态变压器。

## 4. 同一环节公司为什么差很多

同环节公司之间的差异，通常不在“有没有产品”，而在以下几项：

| 维度 | 问题 | 例子 |
|---|---|---|
| 产品结构 | 是低端通用品，还是高端品类 | 玻纤中粗纱 vs Low DK 电子布 |
| 客户结构 | 绑定头部客户，还是长尾客户 | 泰山玻纤绑定华为昇腾链，天孚进入全球光模块客户 |
| 一体化能力 | 只做单环节，还是上下游打通 | 云天化磷矿到磷化工，汇川伺服到 PLC/控制 |
| 成本曲线 | 是否掌握低成本产能 | 硅料、钛白粉、维生素 |
| 扩产节奏 | 景气来时是否已有产能 | CoWoS、海缆、电子布 |
| 现金流 | 涨价是否变成利润和现金 | 锗价上涨但云南锗业利润下滑 |

## 5. 新手最容易犯的三个错

> [!warning] 错误一：只看行业贝塔
> 行业景气不代表全员受益。玻纤、维生素、储能、光伏都显示出同一规律：景气期真正赚钱的是有结构优势的公司。

> [!warning] 错误二：把价格上涨等同于利润上涨
> 小金属锗就是反例。价格涨了，但原料和单位成本涨得更快，利润可能被吞掉。

> [!warning] 错误三：把“国产替代”当成万能答案
> 国产替代要看替代的是哪一层：设备、材料、系统、软件生态还是客户认证。替代难度、兑现周期和利润率完全不同。

## 6. 本教程的学习目标

学完后，你应该能把任意一篇行业文章改写成三张表：

1. 产业链关系表：上游、中游、下游分别是谁，怎么互相影响。
2. 利润池判断表：哪一环节最稀缺，为什么稀缺，是否可持续。
3. 公司对比表：同一环节的龙头、跟随者、纯标的、弹性标的、风险标的。

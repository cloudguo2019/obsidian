# 交易体系底层逻辑

#trading-mindset #trading-system

## Overview Table

| Layer | Key Point |
|-------|-----------|
| 思维具象化 | 把心法落成买什么、何时买、买多少、何时卖。 |
| 系统性思维 | 选股、择时、仓位、风控、复盘要互相一致。 |
| 股票定价 | 股价由预期、资金、供需和市场认知共同驱动。 |
| 第一性原理 | 交易的核心是处理风险收益和不确定性。 |
| 价格发现 | 走势反映市场共识变化，是选股和验证工具。 |
| 第一目标 | 不是单笔盈利，而是长期活下去并执行正期望。 |
| 一致性原则 | 方法一致、行为一致、复盘标准一致。 |

## Four Questions Of A Trading System

```text
买什么
  -> 何时买
    -> 买多少
      -> 何时卖
        -> 复盘是否一致
```

| Question | Must Define |
|----------|-------------|
| 买什么 | 市场范围、主线、强弱、排除条件。 |
| 何时买 | 入场信号、确认条件、无效条件。 |
| 买多少 | 仓位比例、最大亏损、加减仓规则。 |
| 何时卖 | 止损、止盈、趋势失效、时间止损。 |

> [!important]
> 体系的作用不是让每笔交易赚钱，而是减少临盘想象，让相同情境下的行为稳定重复。

## Consistency Checklist

| Check | Question |
|-------|----------|
| 方法一致 | 今天的买卖逻辑是否和过去规则一致？ |
| 行为一致 | 我是否按信号行动，而不是按情绪行动？ |
| 风险一致 | 单笔亏损是否仍在可接受范围内？ |
| 复盘一致 | 我是否用同一套标准评价盈利和亏损？ |

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|------------------|--------|
| “体系要预测明天涨跌” | 错。体系用于定义条件、行动和风险。 |
| “有买点但不知道买多少” | 体系不完整，缺仓位规则。 |
| “止损时找理由不卖” | 违反一致性原则。 |
| “走势是最好的选股工具” | 价格发现机制：强势走势反映资金和预期变化。 |

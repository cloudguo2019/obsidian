# 思维偏见与误区

#trading-mindset #trading-bias

## Overview Table

| Bias | Trading Risk | Correction |
|------|--------------|------------|
| 达克效应 | 能力低估风险，高估判断 | 承认无知，用记录校正 |
| 思维定式 | 用旧经验套新市场 | 让规则随事实更新 |
| 线性思维 | 以为利好必涨、利空必跌 | 事实检验、反向检验 |
| 证实性偏见 | 只找支持持仓的信息 | 主动找反证 |
| 后视偏差 | 事后觉得一切显而易见 | 保留当时决策记录 |
| 锚定效应 | 被成本价、目标价锁住 | 重新评估未来风险收益 |
| 瓦伦达效应 | 越想赢越无法执行过程 | 专注流程而非结果 |
| 有限注意力 | 被过多信息干扰 | 简化关注清单 |
| 沉没成本 | 因过去投入继续错误 | 只看未来 |
| 随机收益 | 把运气当实力 | 扩大样本、看一致性 |
| 近因效应 | 被最近盈亏影响仓位 | 用长期统计约束 |
| 好公司/好投资混淆 | 好公司也可能贵 | 区分质量、价格、时机 |
| 自我归因 | 盈利归功自己，亏损怪外界 | 统一复盘标准 |

## Bias Correction Flow

```text
观点出现
  -> 写下依据
  -> 寻找反证
  -> 检查价格行为
  -> 检查体系信号
  -> 执行或放弃
```

> [!tip]
> 偏见不是靠“提醒自己客观”就能消失，而是要用交易记录、反证清单和固定流程约束。

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|------------------|--------|
| 利好公布但股价不涨 | 用反向检验：该涨不涨就是弱。 |
| 最近三笔盈利后加大仓位 | 可能是近因效应和随机收益。 |
| 成本价附近舍不得卖 | 锚定效应和沉没成本。 |
| 只看唱多研报 | 证实性偏见。 |

# 交易至简简放 学习地图

#dashboard #trading-mindset #trading-psychology

> [!important] 学习目标
> 把《至简交易》的核心从“找方法”转成“训练心智”：控制自己、顺应市场、执行体系，并用练习题把每章概念变成可复盘的行动标准。

## Learning Path

```text
痛苦与错误
  -> 思维偏见
    -> 赢家思维
      -> 交易体系
        -> 交易心理
```

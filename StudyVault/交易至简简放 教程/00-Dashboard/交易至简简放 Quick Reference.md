# 交易至简简放 Quick Reference

#dashboard #trading-mindset

## 痛苦根源 -> [[痛苦根源与交易错误]]

| Concept | One-Line Rule |
|---------|---------------|
| 不知道怎么做 | 缺少清晰体系时，市场每一次波动都会变成心理噪音。 |
| 知道但做不到 | 认知没有转化为行为，本质仍是伪认知。 |
| 正确对待错误 | 单笔亏损不等于错误，违背规则才是错误。 |

## 思维偏见 -> [[思维偏见与误区]]

| Bias | Correction |
|------|------------|
| 达克效应 | 先承认自己不知道，再让交易记录校正认知。 |
| 线性思维 | 用事实检验和反向检验代替“利好必涨”。 |
| 证实性偏见 | 主动寻找反证，而不是只找支持自己观点的信息。 |
| 沉没成本 | 决策只看未来风险收益，不为过去投入加仓或死扛。 |
| 近因效应 | 不让最近几笔交易决定下一笔仓位和情绪。 |

## 赢家思维 -> [[交易赢家思维模式]]

| Mindset | Action Cue |
|---------|------------|
| 空杯思维 | 先看市场事实，再下判断。 |
| 概率思维 | 接受不确定性，只追求长期期望为正。 |
| 跟随思维 | 不预测市场，只在信号出现后顺势反应。 |
| 右侧思维 | 等趋势确认，不抢证明自己聪明的左侧。 |
| 知止思维 | 退出规则比入场理由更能保护本金。 |

## 交易体系 -> [[交易体系底层逻辑]]

| System Question | Required Answer |
|-----------------|-----------------|
| 买什么 | 选股范围、主线条件、强弱标准。 |
| 何时买 | 入场信号和确认条件。 |
| 买多少 | 仓位、风险敞口、单笔亏损上限。 |
| 何时卖 | 止损、止盈、趋势失效、持仓复盘。 |

## 心理构建 -> [[交易赢家心理构建]]

| Principle | Practice |
|-----------|----------|
| 顺应外部变量 | 市场无法控制，只能跟随和反应。 |
| 控制内部变量 | 仓位、止损、执行、记录、情绪处理是自己的责任。 |
| 无我心理 | 做想法的观察者，不把观点当成身份。 |
| 事上练 | 在真实交易、复盘、生活自律中训练一致性。 |

## Must-Know Patterns

- `市场事实 -> 体系规则 -> 行动 -> 复盘` -> [[交易体系底层逻辑]]
- `信号出现才行动；没有信号不创造信号` -> [[交易赢家心理构建]]
- `控制自己，顺应市场` -> [[交易赢家心理构建]]

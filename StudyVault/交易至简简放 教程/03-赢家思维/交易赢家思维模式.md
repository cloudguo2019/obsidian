# 交易赢家思维模式

#trading-mindset

## Overview Table

| Mindset | Core Meaning |
|---------|--------------|
| 空杯思维 | 放下已有结论，先看事实。 |
| 辩证思维 | 同一规则在不同情境下有不同边界。 |
| 概率思维 | 单笔不确定，长期靠正期望。 |
| 跟随思维 | 不预测，只对市场信号反应。 |
| 右侧思维 | 等趋势确认后再参与。 |
| 主线思维 | 聚焦市场最强方向。 |
| 强势思维 | 选强势主线和强势个股。 |
| 试错思维 | 用小风险换取确认机会。 |
| 复利思维 | 控制回撤，让收益可持续。 |
| 知止思维 | 知道何时不做、何时退出。 |
| 第一时间思维 | 信号出现时及时行动。 |
| 周期思维 | 理解不同周期的机会和风险。 |
| 全局思维 | 把单笔放进整体系统看。 |
| 鱼漂思维 | 只盯自己的信号，不盯所有波动。 |
| 击球区思维 | 等最适合自己的位置。 |
| 错过思维 | 接受错过，保护执行质量。 |

## From Mindset To Action

```text
空杯看事实
  -> 概率接受不确定
    -> 跟随市场信号
      -> 只打击球区
        -> 用知止保护本金
```

## Simplification With Exceptions

> [!warning]
> “跟随”不是追涨杀跌；它要求趋势、位置、风险边界同时满足体系条件。

> [!warning]
> “右侧”不是永远等到很晚才买；它强调确认，而确认标准应由体系提前定义。

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|------------------|--------|
| 想预测最低点 | 缺少概率和右侧思维。 |
| 所有板块都想做 | 缺少主线和击球区思维。 |
| 一亏就否定体系 | 缺少全局和概率思维。 |
| 害怕错过而追高 | 缺少错过思维和知止思维。 |

# 痛苦根源与交易错误

#trading-mindset #trading-psychology

## Overview Table

| Item | Key Point |
|------|-----------|
| 痛苦来源 | 不知道怎么做，或知道但做不到。 |
| 交易错误 | 不是亏损本身，而是行为偏离体系、事实和风险边界。 |
| 成功特征 | 有标准、有耐心、能承担结果、能持续复盘。 |
| 修正方向 | 把情绪问题翻译成规则问题、仓位问题、认知问题。 |

## 痛苦的两层结构

```text
市场波动
  -> 触发观点、仓位、预期
    -> 与事实不一致
      -> 内心抵抗
        -> 冲动交易 / 犹豫 / 推责 / 死扛
```

第一层痛苦是“不知道怎么做”：没有入场、止损、仓位、退出标准，市场每一次波动都需要重新判断。

第二层痛苦是“知道但做不到”：规则写得清楚，但临盘被贪婪、恐惧、幻想、侥幸牵引。

> [!warning] Exception
> 亏损不是自动等于错误。只要交易符合体系、风险可控、复盘能接受，它就是概率成本；违背规则后赚钱，也可能是危险的随机奖励。

## 常犯错误

| Stage | Errors | Better Question |
|-------|--------|-----------------|
| 交易前 | 情绪化交易、没有交易标准、系统过复杂、缺乏耐心、消极看待市场 | 我是否知道“什么情况才做”？ |
| 交易中 | 逃避现实、内心冲突、活在幻想中 | 当前事实是否已经触发规则？ |
| 交易后 | 推卸责任、抗压差、缺乏风险意识 | 这笔交易是规则问题、执行问题，还是样本内亏损？ |

## 成功交易者特征

| Trait | Trading Meaning |
|-------|-----------------|
| 坚韧 | 能承受试错和回撤。 |
| 果断 | 信号出现后行动，不在规则内犹豫。 |
| 专注 | 做自己体系内的机会。 |
| 独立思考 | 不用市场噪音代替判断。 |
| 耐心 | 等待可交易位置。 |
| 自省 | 把结果转成复盘材料。 |
| 诚实 | 不用借口掩盖违背体系。 |
| 自律 | 让行为稳定重复。 |

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|------------------|--------|
| “亏了，所以这笔交易错了” | 不一定。先检查是否符合体系和风险上限。 |
| “这次破例赚钱了” | 警惕随机奖励强化坏行为。 |
| “总是下不了止损” | 不是市场问题，是内部变量和执行训练问题。 |
| “体系越复杂越安心” | 复杂可能只是给情绪更多解释空间。 |

# CPA 历年真题（2015—2025）

本目录按中国注册会计师全国统一考试专业阶段六科整理，共 11 年 × 6 科 = 66 份。

## 来源口径

- 2015—2019：东奥会计在线公开的历年真题 PDF；文件中部分题目注明按后续教材重新表述。
- 2020—2021：chinalawyer.co 公开题库为主；2020 年审计采用东奥公开 PDF，2020 年财管采用希赛网公开页面。网页资料为便于离线使用，本地打印成 PDF。
- 2022—2025：东奥会计在线公开的试题及答案解析 PDF；2025 年明确为考生回忆版。
- 中注协说明考试启用后的完整试题、参考答案与评分标准通常按工作秘密管理，因此这些资料不应当称为“中注协官方完整原卷”。来源入口可见中注协备考助手的“往年部分真题”。
- 税法、经济法、会计准则等会随年度变化；旧题主要用于题型、命题方式和迁移训练，作答规则以目标考季大纲和现行法规为准。

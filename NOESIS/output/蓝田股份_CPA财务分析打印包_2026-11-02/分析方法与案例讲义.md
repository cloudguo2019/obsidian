材料截止：2026-11-02。历史分析窗口：1996-2003年。

这套材料按“已经学完 CPA 六科”设计。目标是形成能迁移到其他公司的财务分析方法：从业务事实出发，锁定报表版本，复算跨表关系，再把异常转化为取证程序。

# 财务分析的固定工作流程

1. 先画业务图。谁生产、谁付款、谁持有资产、谁承担风险？列清上市公司、子公司、控股股东及关联方。
2. 冻结信息时点。先只用2001年10月26日前可获得的信息作判断，再打开后续更正和调查材料。
3. 建立数据底稿。每个数同时记录期间、单位、合并范围、披露日期、调整版本、审计状态和来源位置。
4. 做三层检查：同一张表是否加总；三张表是否勾稽；报表能否与产量、价格、人员、能耗和物流相容。
5. 寻找组合异常。单一比率只说明一个侧面，多项独立异常形成同方向指向才提高调查优先级。
6. 为每个异常列正常解释和反证。不能只搜支持造假的材料。
7. 设计能区分不同解释的外部取证。把“怀疑收入”写成客户、银行、物流、税务和生产记录的具体核查。
8. 写分层结论：披露事实、计算结果、风险判断、已认定违法、仍待取证。保留无法回答的问题。

最终成果应是一页判断、可复算数据表、一张证据矩阵和未解决事项清单。

# 把 CPA 六科连成一套方法

| 科目 | 在本案中要解决的具体问题 | 交付物 |
| 会计 | 收入真实性、成本完整性、工程资本化、减值、合并范围及差错更正 | 科目与交易链对应表 |
| 财务成本管理 | 盈利、营运资本、现金去向、周转与偿债期限是否协调 | 统一口径比率与现金桥 |
| 审计 | 哪些认定可能重大错报，怎样取得充分适当的证据 | 风险与审计程序矩阵 |
| 公司战略与风险管理 | 扩张、治理、关联网络和内部控制为何失效 | 业务约束与控制缺口图 |
| 税法 | 业务类别、免税范围、开票和税款能否旁证收入 | 按产品/主体分组的税务勾稽 |
| 经济法 | 发行和披露义务、公司治理、担保及责任边界 | 按当时规则核查的时间线 |

财务分析的增量来自把知识联结起来。例如：会计发现应收很低，财管解释现金周期，审计向银行和客户取证，战略解释控制失效，税法和经济法提供外部约束。

现代CPA方法用于训练。1990年代至2000年代初行为的违法评价，须依据当时有效的规则和具体认定。

# 先画清“谁是谁”

分析主体是上市公司蓝田股份，证券代码600709，后来更名为湖北江湖生态农业股份有限公司，简称ST生态。

不要把“中国蓝田总公司”“洪湖蓝田经济技术开发有限公司”和上市公司视为一个法律主体。披露中的控股股东、共同任职和代销关系，需要分别验证。

业务和资金至少画三条线：

1. 生产线：上市公司及子公司→养殖、农产品和饮料→客户或代销商。
2. 资金线：客户→收款账户；银行→借款人；借款人/上市公司→工程承包方与关联方。
3. 权利线：谁拥有土地使用权、鱼塘、厂房和子公司股权；谁为谁提供担保。

S08和S06披露中国蓝田支付广告费；S02审计报告还指出未披露子公司及关联结构无法核实。这会同时影响费用、收入、存货、合并范围和担保完整性。

同址、同名、同一管理人员是调查线索。控制关系的结论仍需股权、协议、决策和资金安排证据，不能只看名称。

# 偿债分析：比率是起点

使用W2的A版还原口径：

流动比率=433,106,703.98÷560,713,384.09=0.7724。

简化速动比率=(433,106,703.98-236,384,086.72)÷560,713,384.09=0.3508。此处为复现历史分析的“流动资产减存货”口径；严格速动资产还应检查预付款和其他难变现项目。

净营运资本=流动资产-流动负债=-127,606,680.11元。

若改用B版流动负债，流动比率约0.6664，简化速动比率约0.3027，净营运资本为-216,814,524.11元。这一差异首先来自版本和股利安排，不能解释成同一期间突然出现的新经营事实。

低比率说明账面短期资产缓冲不足。是否违约，还取决于债务到期表、受限资金、可持续经营回款、授信及资产变现能力。快速周转的现金生意也可能具有负营运资本。

本案的调查重点是：高现金销售、高利润和高经营净现金的披露，能否与紧张的可用资金、扩张中的资产及银行融资相互解释。

# 现金分析：不能把蓝田讲成负经营现金流

按S18旧现金流辅助转录，单位万元：

78,582.96-71,531.62-9,612.46=-2,561.12。

经营净现金约7.8583亿元，是正数；相对旧披露净利润约为1.82倍。经营净现金÷原流动负债约1.40倍。因此不能写成“经营现金流为负”或“这一比率很低”。

购建长期资产现金71,932.34万元，约占经营净现金91.54%。简化自由现金流=78,582.96-71,932.34=6,650.62万元，也仍为正数。该定义包含披露的全部购建长期资产支出，不等于维持性自由现金流。

现金净减少来自经营、投资、筹资共同作用。经营净流入高，并不自动证明回款真实；工程大额流出也不自动证明其虚构。两端都需要外部取证。

三类现金净额的平衡只是算术一致。若把借款流入错列为销售回款，或者通过虚构回款与工程支出配对，三表也可能表面平衡。这是待验证机制，不是本包已经证明的具体作案路径。

数据精度：S18单位为万元、两位小数；CFO与S11约7.86亿元一致。未取得2000年报现金流原表，不将转录精度冒充原件精度。

# 收入分析：让数量、单价和现金互相约束

S06中，公司对低应收的解释是现场成交、个体客户多、现金结算便利。应先保留这一正常解释，再测试其规模是否可行。

| 业务环节 | 核查方法 | 重要的替代解释 |
| 生产 | 按产品核养殖面积、投苗、饲料、周期、死亡率及收获记录 | 外购转售；面积和品种结构差异 |
| 销售 | 客户穿透、销售日记账、出门单、称重及运输路线 | 批发集中采购、季节性销售 |
| 收款 | 全部账户流水、现金缴存、客户付款来源、期后回转 | 合理账期与现金偏好 |
| 成本 | 饲料、原料、包装、外包和能源与销量勾稽 | 一体化成本优势、外包生产 |
| 饮料 | 包材数量、灌装能力、经销商库存和终端动销 | 代工、跨区域销售 |

低应收不等于好收入，也不等于假收入。将某行业平均账期视为所有企业应有账期，会忽略客户与产品结构。

同业比较需同年、同产品、同环节、同合并范围。S10的同业推理是历史分析样本；本包未取得其全部同业原始数据，不能声称已完整复算该比较。

# 工程、固定资产和存货：利润可能藏在哪里

S01第17-18页提供在建工程项目，第11页列制度衔接减值；S06解释折旧年限、工程重分类及长期待摊费用。它们提示资产端需要深入核查。

先区分四个问题：工程是否存在；公司是否拥有权利；成本是否真实完整且符合资本化条件；账面价值能否收回。

资本化测试：把维修、日常生产、广告或不具备未来收益的支出长期挂账，会推迟费用确认。审计须取得合同、工程量、验收、付款及受益期证据，而不能只看发票或评估结论。

折旧、摊销和减值测试：变更理由是否有新事实支持；何时达到可使用状态；是否应转固；后续产出是否支持可收回金额。会计估计变更与前期差错应分别判断。

存货测试：按品种和生产阶段核数量、成本和可售性；水下养殖需要适合其特点的盘点、抽样及专家协助。历史报表的“在产品”不能不经辨别直接改称现代准则下的某类生物资产。

资产占比高是业务解释和调查入口，不能单凭“高于同业”断定资产不存在。

# 关联方、税务和治理的交叉检查

广告费用：S08和S06披露中国蓝田签约付款，上市公司未支付亦未承诺未来支付。需要检查合同、实际受益人、是否存在补偿或其他对价、代销条件及披露完整性。盈利可持续性分析可另估独立承担营销的成本，但不能无证据直接补记会计费用。

资金和担保：逐主体列借款、担保、股权质押、往来款和代收代付，追踪资金最终流向。关系复杂本身不是违法证明；账外负债和未披露子公司则涉及报表完整性。

税务：按养殖、初加工、饮料、宾馆等产品及法人主体区分税种、税基和优惠。用当年申报表、优惠批准、发票、税款缴纳及税务检查与销售核对。不能用2026年的税率倒算2000年应纳税额；免税业务也可能有纳税申报和生产记录。

治理：检查管理层凌驾控制、工程采购与付款授权、印章和账户管理、关联方识别、子公司报送、内部审计和董事会监督。行业景气或农业扶持可以解释扩张动机，不能替代对交易真实性的证据。

# 从异常到审计程序

| 风险 | 关键认定 | 可以区分解释的程序 |
| 销售或回款虚构 | 发生、准确性、截止 | 客户独立函证；验货/运输/收款穿行；期后冲回；资金来源穿透 |
| 银行余额及账外借款 | 存在、权利、完整性 | 独立控制银行函证；账户完整性；受限资金；余额调节及期后流水 |
| 工程与资产虚增 | 存在、权利、计价 | 实地检查与工程专家；承包商函证；工程量、合同、付款及转固时点 |
| 关联代销存货 | 存在、权利、可变现性 | 代销协议；受托方盘点/函证；终端销售；期后退回及减值 |
| 子公司和担保漏报 | 完整性、列报 | 工商/法律记录；银行与律师询证；董事会记录；合并范围测试 |

程序须回应具体认定。函证由审计师控制选样、寄发及回收；管理层转交的回函或对账单需特别核验。未回函要考虑替代程序和局限，不能直接当作已证实余额。

附录S13/S14提供现代函证和分析程序准则，作为方法训练。分析程序发现异常后需要解释与其他证据支持，不能只靠比率出具舞弊定论。

# 现有材料到底证明了什么

第一层：S08转述1999处罚，明确发行申报中虚增无形资产1,100万元、伪造银行对账单虚增银行存款2,770万元，合计资产3,870万元。这是发行申报事项，不是后续年度虚增利润总额。处罚书官方原件未取得。

第二层：S01/S06足以提出关于销售模式、扩张、资本化、流动性和关联网络的具体调查问题。事前可以要求强化授信条件、核查回款和抵押资产，而无需先证明全部造假。

第三层：S02第20-21页审计报告记录账务系统并存、原资料被查封、代销证据不足、未披露子公司、工程权属及借款完整性等障碍，最终无法表示意见。它比单一比率异常更直接地揭示财务信息基础失效。

第四层：S02/S03披露大幅重编与继续更正，同时持续无法表示意见。因此本包能系统分析已知发行造假、公开报表严重失实和审计证据断裂；不能还原每笔虚构交易、最终资金流向或法院确定的全部损失。

可负责的结论是：重大疑点已足以触发高强度核查，后续原始披露证实原财务信息的可靠性出现严重问题。完整司法造假总额仍须原判决、鉴定和底层账证支持。

W1：至少区分原年度披露、制度衔接/股利调整后的中报比较数、另一账套重编三层。2001中报未经审计；2001年报无法表示意见。不得用“已经审计”泛称所有版本。

W3：现金桥成立；CFO/净利约1.82；购建支出/CFO约91.54%；简化FCF约6,650.62万元。正现金流也须核真实性和分类。

W4-W5：合格答案要给正常解释、可区分解释的外部证据及认定，不能只写“函证、盘点”几个程序名称。真实资金入账也应检查是否来源于借款、关联方循环或期后回转。

W6：必须区分事前风险与事后证据、转录与原件、重编差额与司法认定。结论强度不能超过证据强度。

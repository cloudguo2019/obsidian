# CPA 历年真题 Markdown 语料库（2015—2025）

本目录是 66 份 CPA 专业阶段历年真题 PDF 的文本镜像，按年份和科目组织，供 Obsidian 与 AI 检索。

## 使用说明

- 每个文件都有 YAML 元数据：年份、科目、来源类型、公开来源链接、原 PDF 路径。
- 正文按 `## 第 N 页` 分段，方便引用与回看原 PDF。
- 文本来自 PDF 文本层自动抽取；公式、表格、分页断行可能失真，以原 PDF 为准。
- 旧年度法规和准则可能失效，训练时应结合目标考季现行口径。

统计：66 份 Markdown，823 页，约 953,423 个抽取字符。

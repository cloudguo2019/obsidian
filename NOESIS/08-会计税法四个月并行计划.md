# 会计与税法四个月并行计划｜2026-10-01—2027-01-31

> [!important] 当前决定
> 10月1日起同时备考会计和税法。四个月内完成两科**全部2026官方大纲列示考点**的首轮教学与独立应用，2027年1月31日不得留有“未学习”或“仅预览”的大纲项目；**会计、税法两科均须通过来源明确、首次作答、版本有效的真实历年试题终验收**。10月7日完成第一周试运行复盘，10月31日完成第一个月复盘；反馈可调整顺序、任务颗粒度和复习比例，但不缩小四个月全覆盖与真题终验收目标。四个月是第一轮正式备考周期，不据此提前决定2027年最终报考科目。

## 计划口径与目标

- 9月的30天用于认识会计基础并验证AI教学闭环；10月1日才开始两科系统学习。会计以9月已学基础为起点，税法从零建立语言和计算框架。两科每周都出现，不把税法留到会计结束后。
- 到1月末，会计30章、税法14章及其大纲列示的下属考点全部完成一轮教学和独立应用。9月接触过的章节先逐项审计，只有已教且经独立应用的子项才算完成；章名、讲义浏览或地形预览不算覆盖。D1/D3/D7/D30、分主题真题与阶段卷同步推进，未达M3的项目进入第二轮清单，但不得留在“未学习”状态。
- 本阶段适配工作间隙：不估算无法可靠取得的“净学习小时”，也不用小时数作为加减科目的闸门。只记录完成的学习块、首次分、到期复提、未见真题、反复错误、任务中断及与工作/量化研究的冲突。完整限时测试可单独记录客观作答时间。
- 会计与税法范围暂依[中注协2026专业阶段大纲](https://www.cicpa.org.cn/xxfb/tzgg/202603/W020260304555799366109.pdf)；统一标记`[2026 临时基线｜待 2027 大纲复核]`。税率、优惠、期限、例外及近年税制变化，每次教学或评分都要先核对适用版本。2027官方大纲发布后作差异更新。

## 全覆盖的完成口径

1. **核对单位是大纲子项，不是章名。**会计第1—30章、税法第1—14章各自的（一）（二）及其下编号考点逐条登记为`未学 / 仅预览 / 已教学待独立应用 / 已独立应用 / 待延迟或真题验证`。周表只负责排期；子项必须按[2026官方大纲](https://www.cicpa.org.cn/xxfb/tzgg/202603/W020260304555799366109.pdf)原文逐条核销，不得用一章的一道题覆盖整章。
2. **首轮完成条件。**每个子项至少完成来源核对、针对其能力等级的教学，以及未见过答案的闭卷独立应用；概念项可用解释与边界判断，计算、分录和综合项须有相应的独立题。答错则补教并用新情境再做，不能把看过答案或提示后的重答记为独立完成。未完成的子项留在任务队列，直至通过。
3. **两个截止点。**每周末核对当周应完成的所有子项；2027-01-25前排完全部44章的首轮教学与独立应用，01-26—01-31专门逐项查漏、补未通过子项及进行已学范围限时测评。01-31覆盖检查须达到两科大纲子项`未学=0、仅预览=0、已教学待独立应用=0`，否则如实记录目标未达成，不把缺口改写为“已覆盖”。
4. **真题是终验收的必要条件。**10-07建立候选题号池，10-31核对主题与税法版本，12-31按题号锁定会计和税法各自的未见真实题组合，01-25复核未见状态与评分依据；覆盖尽可能多的已学章节与客观、主观题型。01-26—01-31闭卷限时首次作答，分别记录合格题目的首次得分、预先锁定且有依据的评分点满分、用时和覆盖矩阵；两科各以**有效真题得分率≥70%**作为本轮阶段验收线，不用两科平均分掩盖一科不足。此线沿用本项目M3的真实题迁移要求，不等同官方CPA合格分或整卷成绩预测。
5. **题源有效性先于分数。**题目须登记来源文件、年份、题号/页码、答案及评分依据、作答前未见状态和当前规则适用性。中注协备考助手只发布往年**部分**真题，不能把拼接题组称为官方完整原卷。已用于教学、已见答案、改写后的旧税法题和AI生成题均不得进入终验收分。若某科找不到覆盖足够主题且规则有效的未见真实题，则该科真题验收记`证据不足`，继续补找可靠题源，不用训练题补位，也不宣布验收通过。
6. **覆盖与掌握分开。**全部学过与两科真实题终验收是四个月的双重门槛；M3还需D7/D30和可靠限时证据。2027官方大纲发布后，对新增或改动内容另做差异学习，不把尚未公布的2027内容冒称已完成。

## 碎片化学习的周循环

每周必须完成下表分配到该周的**全部大纲子项**的教学和独立应用，同时安排两科到期复提，以及一次混合应用或来源明确的真题。大章可跨相邻周，但其每个子项必须有明确的截止周；周复盘发现遗漏时，立即在随后一周安排补齐，不把遗漏留到1月最后一天。不预设固定学习小时，实际任务量以全覆盖截止点反推。

| 可用窗口 | 做什么 | 交付物 |
|---|---|---|
| 5—10分钟 | D1/D3/D7闭卷提取或一题错因复提 | 首次答案与下次日期 |
| 15—25分钟 | 一个小教学块：业务事实→概念/规则→示例→本人复述 | 一条判断树和一题独立应用 |
| 25—45分钟 | 完整分录、税额计算、章节变式或来源明确的旧题 | 未提示的首次答案、评分与修复 |
| 有连续时段时 | 两科交替的综合案例、周测或月测 | 覆盖范围、首次分、用时（若可靠） |

工作日按出现的窗口取任务，不补造打卡时长；周二、周四继续保护量化研究。忙周把大章拆成更多小块，并在下一可用窗口补齐该周子项；周复盘同时检查两科覆盖债务和复提债务。若计划进度已经威胁1月25日排完全部内容，优先调整任务颗粒度与练习量，保留每项的独立应用，不用“看过一遍”冲抵。没有连续时段时，测试仍须独立提交后再看反馈。

## 真题怎么分配

详细使用状态记在[[93-真题使用登记]]。现有中注协备考助手下载件是**往年部分真题**，不是完整官方原卷；本地2015—2025整理件还有公开整理、按后续教材改写和考生回忆版。题源等级与答题规则分开核对。

1. **先锁终验收池，再分配学习题。**10-07在[[93-真题使用登记]]中只登记候选题的来源、年份、题号和覆盖主题，不给学习者看题干或答案；10-31检查能否覆盖两科主要模块以及税法规则版本，12-31锁定终验收题号。2023年中注协备考助手部分真题优先保留；如题量或适用主题不足，从2022年及更早尚未见过的合格题中按题号补充。池不足时继续核找来源明确的真实历年题，不能以AI题凑验收分。
2. **学习时仍用真题。**已教完的知识块先做独立变式，再从未进入终验收池的2019—2021年中注协备考助手会计/税法部分真题挑适配题。2022年按题号分给周末/月末测评或终验收，不整年笼统占用。每题记录原件、年份、科目、题号、是否首次见题；税法旧题先审适用版本，事实或规则改写后的题只能记训练分。
3. **补充题库**：2015—2018及2024—2025公开整理版用于补题型、追问和变式；2025考生回忆版不得称为官方原卷。它们可帮助训练，但来源或现行规则不明时不作为主要阶段分数。
4. **防止污染**：测评前不向学习者展示题干、答案或解析；同一道题用于教学后，永不再计“未见首次分”。章节练习与月末保留题按题号登记，而不是只按年份笼统封存。

## 两个反馈闸门

**10月7日：检验运行方式和首周覆盖。**看两科是否实际完成W1全部大纲子项的“教学→独立应用→订正/复提”，工作间隙能否启动，哪些步骤需要连续时间，D1/D3是否积压；同时建立两科真题终验收候选题号池。若一周被打断，拆小单元并明确补齐窗口；不因小时数未知就判定失败，也不把尚未做的子项改记完成。

**10月31日：检验第一月的覆盖与学习结果。**先逐条检查W1—W4已排的会计、税法子项是否全部独立应用，再看闭卷首次分、D7、来源合格的未见题、反复错因与复习债务；检查终验收候选题是否有足够主题广度及适用版本。若有覆盖或题源债务，给出11月补齐日期，并调整任务颗粒度、章节顺序或练习量；不削减四个月全覆盖与真实题验收范围，不倒填净学习时长。

**2027年1月31日：全覆盖与真题双验收。**先依2026官方大纲逐条清点会计30章和税法14章的所有列示子项：`未学=0、仅预览=0、已教学待独立应用=0`；再分别报告两科闭卷限时、来源及版本合格的未见真实历年题首次分，达到各科≥70%的阶段线。附上题号覆盖矩阵、D7/D30、M2/M3分布、反复错误和下一轮重学清单。任一科缺合格真题证据、低于阶段线，或任一子项未完成首轮，都不能宣布四个月双验收通过。2027大纲发布后另行核查新增或变动内容。

若要判断AI是否优于别的方法，应与真实可行的备考替代方案比较，而不是要求在相同的整块课堂时间内对照。这个四个月周期首先检验：无需老师在场或特殊环境，是否能把工作间隙持续转化为两科的学习、复习与未见题表现。

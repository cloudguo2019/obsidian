# CG-CPA 长期记忆与跨对话交接

本文件供 `$cg-cpa` 在新对话中恢复教学上下文。它只保存会改变后续决策的长期事实和当前检查点，不保存聊天原文，也不替代项目台账。

## 权威顺序

出现冲突时按以下顺序处理：

1. 用户在当前对话中的明确要求。
2. `00-NOESIS控制台.md`、`05-30天启动计划.md`、`90-学习错误与问题台账.md` 的最新日期记录。
3. 本记忆文件。
4. 旧对话摘要或模型记忆。

如果本文件落后，只修订“当前检查点、进度摘要、到期复习”，不要擅自重写项目目标。

## 项目身份与目标

- 项目：NOESIS，检验 AI 能否作为主要认知接口，帮助全职工作的零基础成年人以更少有效小时获得更高的延迟保持率、真实题迁移率和 CPA 考试成绩。
- 唯一终局指标：CPA 成绩；看懂、流畅感、对话时长和完成页数都不是掌握证据。
- 起点：2026-09-01；正式学习始于 2026-09-02。
- 长期报考路线待正式学习反馈决定；当前已确定2026-10-01—2027-01-31会计、税法两科并行备考。
- 第一阶段：2026-09-01—09-30，只验证“会计基础 + AI 原生学习闭环”能否稳定运行，不追求学完会计。
- 2026-09-28用户重新确定：9月基础摸底与闭环验证成功；2026-10-01—2027-01-31正式同时备考会计、税法，09-29—09-30轻量启动，10-07和10-31先后复盘一周与一月，之后按反馈调整。权威执行计划为[[08-会计税法四个月并行计划]]，真题使用见[[93-真题使用登记]]。
- 2026-09-30用户进一步明确：四个月须覆盖会计与税法全部考试大纲内容，1月31日不能留未学习项。以2026官方大纲为临时基线，按会计30章、税法14章的所有列示子项逐项教学并独立应用；2027新大纲发布后另做差异学习。M3掌握验证与全覆盖首轮目标分开记录。
- 2026-09-30用户再明确：四个月终验收必须用会计、税法各自未见且版本有效的真实历年题。10-07建候选题号池、10-31核源和税法版本、12-31锁定、2027-01-26—01-31闭卷限时首次作答；两科各按预先锁定的有效评分点达到≥70%才过阶段真题线，缺合格题源记证据不足。详见[[08-会计税法四个月并行计划]]和[[93-真题使用登记]]。
- 学习利用工作间隙，无法可靠估算净学习小时；不以小时数做本阶段的强制评价或科目闸门。记录完成的任务、到期复提、未见题首次分和可靠的限时测试时间；周二和周四优先保护量化研究。
- 当前方法：`A = AI 原生`。学习单元通常只能在当日达到 `M2`；`M3` 需要闭卷解释、新变式、来源明确的未见真实题、D7/D30 保持和考试时间可用性共同验证。

## 学习者画像与互动偏好

- 使用中文教学。学习者会计起点接近零，但对经济业务、资产负债恒等式和现金/利润差异形成了较好的直觉。
- 喜欢直接进入任务，不需要长篇鼓励、重复背景或装饰性总结。
- 10-07明确要求全面查档并同步，避免重复确认已学内容。备课先按90原课证据抵扣已通过部分；记录缺失由教师查档，不能让用户重新证明是否学过。已教未答只补应用，正常复习明确标用途，保持原学习日与已通过状态。
- 冷启动必须先让学习者预测，再给完整题组；学习者一次性提交后才评分。测试期间禁止提前提示或讲解。
- 必须区分“已学内容的闭卷提取”和“新单元冷诊断”。已学内容可以先测后评；新单元的冷诊断只能检查前置知识和直觉，不得要求尚未教过的准确账户、公式、术语或完整处理程序。
- 2026-10-11用户明确：每个A/T编号（如A04-01）是一轮教学。一次消息完整讲清本模块尚未学习的内容、边界、准确账户/计算和必要示例，并附完整独立题组；学习者一次提交本模块答案。不得因内容多拆成多轮，也不插入例行“是否理解/是否继续”确认。已教部分保留；已经拆开的模块，将剩余教学与待答题合并到下一次消息。评分通过后可在同一消息简评并进入下一完整模块；实际错误只作必要的定向修复。尊重用户主动中断和时间上限，完整覆盖与验收要求保留。
- 新知识应按“业务事实 → 经济实质 → 规则 → 准确账户/计算 → 示例”完成一个计划编号的教学，再让学习者独立应用。不得让学习者在尚未获得必要知识后，仅靠纠错反馈猜出规范分录。
- 未教内容暴露出的空白只是教学起点，不记为学习错误，不计算信心偏差，也不进入长期错误台账；若题目越过教学边界，应作废受影响的分数并重新教学。
- 答错后先指出具体缺口，要求本人修复；不要直接替他重写全部答案。
- “账户”“本期发生额”“期末余额”等术语如果首次出现，要用业务语言解释，不能假设已经理解。
- 中途被工作或吃饭打断时，按用户明确指定的计划时间或有效对话区间记录，不能自行把整段墙钟时间算作专注时间。
- 用户曾明确要求：只改指定内容，其余不动。提交、同步和推送必须另有明确授权。

## 固定教学流程

1. 读取项目与本记忆，确认最新完成日、到期复习和今日上限；按90原课证据直接抵扣已过细项。当前有效原答案优先于交接简写，历史编辑分支不覆盖有效评分。
2. 先标明当前任务属于：已学内容提取、新单元前置诊断、教学后练习或出口测试。
3. 对已学内容，如计划要求先记录预测，再一次给出完整闭卷题组；提交后评分、诊断并修复。
4. 对新单元，仅在确有必要时另作前置诊断；只测已学前置知识或无需术语的业务直觉。不得用尚未教学的账户名称、公式和程序给学习者正式扣分。
5. 按完整A/T编号一次教学：业务事实 → 经济实质 → 规则 → 准确账户/计算 → 必要的完整示例，并在同一消息附本模块全部独立题。确认所需知识已教后，让学习者一次作答；内容较多时在消息内组织，不再拆轮。
6. 教学后的错误才按 `K/B/R/P/C/Q/M` 找一个主因；解释缺失区别，并要求学习者本人完成修复。同日修复不等于延迟掌握。
7. 本模块提交后整体评分；无需修复时，简评与下一完整编号合并交付。不要提前结束，也不要无视时间上限追加内容。
8. 出口测试完成或用户叫停后再更新正式学习记录。

输出前必须做语言检查。禁止出现读不通的压缩句、残留模板词、无意义英文碎片或中英粘连，例如曾出现的错误句式“`ploit才会逐期受到影响`”。遇到上下文疑似压缩时，不凭模糊印象继续，应重新读取本文件和项目最新状态。

### 存货

- 存货的三类情形：持有以备出售、正在生产以待出售、将在生产或提供服务中消耗。
- 初始成本包括采购成本、加工成本和其他使存货达到当前场所与状态的成本。
- 可抵扣增值税不计入存货成本；正常生产人工和合理分配的制造费用计入加工成本。
- 完工后普通仓储费、广告费和非正常损耗通常进入当期损益。
- 允许的方法：个别计价、先进先出、月末一次加权平均、移动加权平均；后进先出不能使用。
- 09-08原独立计算：先进先出1280/1120、月末平均12/1440/960合组6/6；移动平均13.5/810/1350组4/4。三法计算已通过，不能再列“未学/待核”；个别计价含义已讲，仅缺逐件计算独立应用。
- 期末按成本与可变现净值孰低计量。期末应有跌价准备是存量，本期补提或转回才是本期损益影响。
- 计提：借“资产减值损失”，贷“存货跌价准备”；账面价值和利润下降，现金不变。转回方向相反。
- 原材料先看其生产的产成品是否减值；需要时用产成品售价减后续加工成本和销售费用税费倒推原材料可变现净值。

### 固定资产：已完成初始计量、折旧、后续支出与处置

- 两项特征：为生产商品、提供劳务、出租或经营管理而持有；使用寿命超过一个会计年度。
- 两项确认条件：相关经济利益很可能流入企业；成本能够可靠计量。
- 10-08 A03-01：购入时即为转售的设备按存货、自用长期设备按固定资产；价格低不能单独排除固定资产。旧特征/确认条件抵扣，新边界6/6及出口通过，后续初始计量仍按原计划。
- 购入成本只包括达到预定可使用状态前必要且可直接归属的支出。可抵扣增值税单独确认；培训费、异常损失及达到可使用状态后的日常维修通常进入当期损益。
- 需要安装时先用“在建工程”，达到预定可使用状态后借“固定资产”、贷“在建工程”。
- 自建工程的正常材料、人工、建造机械折旧、必要调试和符合资本化条件的借款利息可进入成本；异常损失不进入成本。
- 法定或合同等弃置义务的现值初始计入固定资产并确认预计负债；该初始确认本身不立即影响利润和现金。
- 生产机器本身是固定资产；机器折旧是固定资产成本的系统分摊，正常生产折旧通过制造费用等进入存货成本，产品出售后转为营业成本。折旧不是资产减值。
- 年限平均法下，每期折旧额以可折旧金额在使用寿命内分配；正常计提按用途借费用或成本、贷累计折旧。固定资产保留原价，账面价值由原价减累计折旧等项目得到。
- 日常维修通常费用化；提高性能且满足确认条件的改良支出资本化。改良期间可先将账面价值转入在建工程，完工后连同资本化支出转回固定资产。
- 处置时先将原价和累计折旧转入固定资产清理，再记录处置收入与费用，清理余额结转资产处置损益。处置损益影响利润，收付现金通常属于投资活动。
- 10-10 A03-04—06：四种折旧法、月度起止/停止范围、寿命残值方法复核与未来适用、改造替换完整分录、毁损及盘盈盘亏已独立应用；普通出售用10-06原通过证据抵扣。毁损/报废与普通出售的损益归属不同，盘盈为前期差错、盘亏按赔偿后净损失处理。具体题/金额见H10，公式边界见91，不重讲已过部分。

### 无形资产与研发支出

- 无形资产是企业拥有或控制的、没有实物形态的可辨认非货币性资产；确认还要求经济利益很可能流入且成本可靠计量。
- 外购成本包括购买价款、相关税费及达到预定用途前直接归属支出；培训和广告通常进入当期损益。
- 研究阶段支出费用化；开发阶段只有“技术、意图、利益、资源、计量”五项同时满足后才资本化，以前已费用化金额不得转回资本化。
- 费用化与资本化支出分别使用“研发支出——费用化支出”和“研发支出——资本化支出”；达到预定用途后，资本化支出转入无形资产。
- 使用寿命有限的无形资产自可供使用时起系统摊销，无法判断利益实现方式时用直线法；使用寿命不确定的不摊销。按用途借费用或成本、贷累计摊销。
- 按月处理时，固定资产当月增加下月折旧；无形资产可供使用当月开始摊销。

### 负债与所有者权益基础

- 负债来自过去交易或事项形成的现时义务，履行预期导致经济利益流出；仅有未来计划且交易尚未发生时通常不确认。
- 能区分应付账款、应付职工薪酬、合同负债、短期借款、长期借款和应付股利，并判断基本流动/非流动分类。
- 投资者投入计入实收资本或股本；超过约定资本的资本溢价计入资本公积，不形成收入或利润。
- 借款本金取得和偿还只改变资产与负债；所有者投入直接增加权益；批准股利直接减少权益并形成负债，实际支付时不再次减少权益。
- 本年利润转入未分配利润、从未分配利润提取盈余公积、资本公积转增资本均为权益内部结转，不改变权益总额。

### 借款费用

- 借款费用可直接归属于需要相当长时间才能达到预定可使用或可销售状态的合格资产时，在资本化期间计入相关资产成本；其他借款费用进入当期损益。
- 开始资本化须资产支出、借款费用和必要购建或生产活动三项同时发生；发生日期不同时取最晚时点。
- 非正常中断且连续超过3个月时，整段中断期间暂停资本化并费用化；达到目标状态所必需的正常程序不暂停。达到预定可使用或可销售状态时停止资本化。
- 专门借款资本化金额为资本化期间实际利息减闲置资金收益；一般借款按实际占用的资产支出加权平均数乘资本化率计算，且不得超过实际利息。
- 资本化通常借记在建工程等相关资产；费用化借记财务费用。未支付利息贷记应付利息；资本化当期不立即减少利润，随后通过折旧或销售成本等影响利润。

### 或有事项：已完成核心确认与计量块

- 由过去事项形成的现时义务，同时满足很可能导致经济利益流出且金额能够可靠计量时，确认预计负债；缺少任一条件时不能确认预计负债，符合定义的或有负债通常只披露、不入账。
- 最佳估计数：等可能连续区间取中间值；单个项目取最可能金额；大量项目按结果与概率加权。
- 第三方补偿只有基本确定收到时才单独确认为资产，金额不得超过预计负债，且不能与预计负债抵销。
- 保证类质量保证不构成单项履约义务时借主营业务成本等、贷预计负债；未决诉讼通常借营业外支出、贷预计负债。未决诉讼及第三方补偿的精确账户在W3首次提取失败，登记E-038后同日订正。

### 政府补助：已完成分类与处理

- 政府补助须来源于政府且具有无偿性；政府采购形成收入，政府以投资者身份投入形成权益，均不属于政府补助。
- 用于购建或形成长期资产的为与资产相关补助，其他为与收益相关补助；分类看经济实质，不能仅因资金未限定用途、晚于建设支出收到或成本已经发生就改判。
- 与资产相关补助的总额法（递延收益分期计入损益）和净额法（冲减资产账面价值），以及收益相关补助对过去/未来成本的处理已用新数字独立应用通过。
- 定义特征是来源于政府、具有无偿性；确认还须企业能够满足所附条件并能够收到补助。两层判断曾混淆并登记E-034；W3 D1再次漏一项条件，订正后完整写出。

### 资产减值：已完成固定资产单项基础块

- 固定资产等适用资产减值准则的长期资产出现减值迹象时，比较账面价值与可收回金额；可收回金额取公允价值减处置费用后的净额和预计未来现金流量现值的较高者。
- 可收回金额低于账面价值时，差额借资产减值损失、贷固定资产减值准备；当期利润和资产下降，现金不变。未来折旧以减值后的账面价值为基础在剩余寿命内分摊。
- 固定资产减值以后期间不得转回，处置时转销准备属于终止确认；存货跌价因素消失时可在原准备内转回。Day23出口首次12/12、Day24 D1通过，仍仅M2，待D3/D7及未见真实题。

### 所得税会计：已完成资产与负债的概念预览

- 税前扣除是在计算应纳税所得额时减去税务允许扣除的金额；可扣除所得额不等于等额减少税款，税款影响还需适用税率。
- 资产账面价值按原价减累计折旧、减值等得到；资产计税基础是未来收回资产时按税法可扣除的金额。简单资产情形下，账面价值小于计税基础形成可抵扣暂时性差异，大于计税基础形成应纳税暂时性差异。
- 负债计税基础为账面价值减未来清偿时可税前扣除的金额。预计负债若未来支付时可扣，当前计税基础可为零，形成可抵扣暂时性差异。具体税务扣除时点以题设与适用规则为准。

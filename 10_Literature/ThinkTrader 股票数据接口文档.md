## 核心脉络

1. [[获取股票概况]]：通过 [[获取合约基础信息数据]]、[[获取板块成分股列表]]、[[获取某只股票ST的历史]] 等接口获取股票或合约的基础属性、板块成分与 ST 历史。
2. [[获取行情数据]]：通过 [[获取历史行情与实时行情]]、[[〖迅投研专属〗获取股票历史涨跌停价格]]、[[〖迅投研专属〗股票快照指标]]、[[涨跌停/集合竞价表现]] 等目录项获取历史行情、实时行情、tick 数据与不同周期 K 线。
3. [[获取股票资金流向数据]] 与 [[获取股票订单流数据]]：用于更细粒度观察成交、委托和资金行为。
4. [[获取问董秘数据]]、[[获取交易日历]]、[[获取龙虎榜数据]]、[[交易所公告数据]]：偏事件、日历和市场公开信息维度的数据源。
5. [[北向南向资金（沪港通，深港通和港股通）]]：包括 [[北向南向资金交易日历]]、[[获取对应周期的北向南向数据]]、[[沪深港通持股数据]]。
6. [[获取单季度/年度财务数据]]：包括 [[财务数据列表]]、[[资产负债表]]、[[利润表]]、[[现金流表]]、[[股本表]]、[[主要指标]]、[[十大股东/十大流通股东]]、[[股东数]] 等结构化数据。

## 接口地图

| 主题 | 代表接口 / 数据 | 备注 |
| --- | --- | --- |
| [[获取合约基础信息数据]] | `get_instrument_detail` | 查询代码、名称、上市退市日期、涨跌停价、股本、交易状态等 |
| [[获取板块成分股列表]] | `get_stock_list_in_sector` | 按板块名称返回股票代码列表 |
| [[获取某只股票ST的历史]] | `get_his_st_data` | 需要下载历史 ST 数据，部分权限受限 |
| [[获取历史行情与实时行情]] | `get_market_data_ex`、`get_market_data`、`get_full_tick` | 覆盖历史行情、实时行情、tick、K 线 |
| [[获取股票资金流向数据]] | 资金流向相关接口 | 可按日级、分钟级或多标的查询 |
| [[获取股票订单流数据]] | orderflow 相关接口 | 主要以 1m 订单流为基础合成其他周期 |
| [[获取交易日历]] | 交易日历下载与查询 | 用于判断市场交易日 |
| [[获取龙虎榜数据]] | 龙虎榜相关接口 | 市场异动和席位数据 |
| [[北向南向资金（沪港通，深港通和港股通）]] | 沪深港通、港股通相关接口 | 包括交易日历、周期数据、持股数据 |
| [[交易所公告数据]] | 交易所公告相关接口 | 市场公开公告数据 |
| [[获取单季度/年度财务数据]] | `get_financial_data`、`get_raw_financial_data` | 包括三大报表、股本、主要指标、股东数据 |

## 使用注意

- 内置 Python 接口通常以 `ContextInfo` 或策略上下文 `C` 为入口。
- 原生 Python 接口通常通过 `from xtquant import xtdata` 调用。
- 很多历史数据接口需要先执行下载函数，否则只能读到本地已有数据或返回空。
- 实时数据通常依赖订阅；没有订阅时可能无法获得最新行情。
- 部分数据属于 VIP 权限或迅投研专属数据。
- 字段命名在新旧客户端中可能存在差异，例如 `FloatVolume` 与 `FloatVolumn`。

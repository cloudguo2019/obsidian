# 研究地图

本目录按“研究主题 → 研究档案类型”组织。每个主题独立保存假设、基准、实验、决策、数据审计和跟踪看板，避免不同策略之间的证据与结论相互污染。

## 主题目录规范

每个主题固定包含：

- `hypotheses/`：研究假设卡
- `baselines/`：基准定义和结果
- `experiments/`：每次实验的配置、输出索引和结论
- `decisions/`：接受、淘汰和变更记录
- `datasets/`：数据版本、口径和审计摘要
- `dashboards/`：样本外和仿真跟踪

实验编号采用 `<策略>-<研究层>-<序号>`，例如 `HD-ANCHOR-001`、`HD-EXEC-002`、`ETF-REGIME-001` 和 `ETF-EXIT-003`。

## 扩展新主题

1. 在 `topics/` 下新建一个语义明确的主题目录。
2. 复制既有主题的七类档案结构。
3. 在本研究地图登记主题、唯一实验编号前缀和研究定位。
4. 不跨主题复用实验编号；可推广的知识通过主题 README 或决策记录显式引用来源。

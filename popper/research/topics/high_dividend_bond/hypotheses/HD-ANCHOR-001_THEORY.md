## 1. 本阶段要回答的研究问题

[研究假设｜C] 如果分红能力在调仓期限内足够稳定，决策时点的股息率可能提供未来含分红收益或风险的信息。以该信息进行相邻库存调整，在承担可比风险并扣除成本后，可能优于静态持有。

[方法选择｜C] 沿用主研究问题：“在只使用历史决策时点可得的分红预期、真实未复权价格、现金分红和可执行成本的条件下，当前股息率滞回策略，是否相对等资金且风险可比的静态持有产生稳定的样本外净增量？”

[研究假设｜C] H1：股息率锚驱动的相邻库存调整，可以提高相对静态持有的含分红净收益，或者在收益相近时降低回撤。

[研究假设｜C] H0：扣除成本并进行风险匹配后，动态调仓没有稳定增量，观察到的优势来自现金仓位、未来信息、特定起点或少数交易。

[方法选择｜C] 上述为待预注册的研究命题；“收益相近”的容忍值和降回撤分支如何与唯一首要指标衔接，须阶段3事前确定，不能看到收益不佳后临时换成回撤指标。

[方法选择｜C] 本阶段分别回答：股息率要求区间为何可能存在；价格锚为何可能有用；分红稳定为何重要；下跌为何可能是坏消息；滞回和分步为何可能减少噪声交易；上涨减仓会损失什么；下跌加仓会积累什么风险。

[已观察事实｜B] 已确认约束为最大回撤16%、修复期6个月、核心仓1000股、主实验从1000股开始，1200股当前持仓和0股起步单列敏感性；正常自动加仓上限1400股、单步100股、确认数2，主执行为同日收盘集合竞价。

## 2. 需要理解的理论和公式

### 2.1 股息率要求区间：由现金流定价出发

[方法选择｜C] 区分三个分红量：实际未来现金分红记为`d_(t+h)`；决策时可得的年度每股分红估计记为`Dhat_t`；已经到账的账户现金分红记为`DivCash_t`。三者不能相互替代。

[研究假设｜C] 在现金流贴现模型中，股票价值取决于未来分配给股东的现金及其风险调整折现。写成`P*_t = E_t[Σ_(h≥1) M_(t,t+h) d_(t+h)]`，其中`M`是折现因子，并要求终值满足相应收敛条件；这是假设下的定价表述，不是对本标的市场价格的观测结论。

[计算结果｜A] 若额外假定年度股利永久按固定`g`增长、要求总回报率固定为`k`且`k>g`，等比级数给出：

```text
P* = D_1 / (k - g)
D_1 / P* = k - g
```

[研究假设｜C] 投资者对利率、权益风险、增长和现金收入偏好的判断不同，因此可能存在股息率要求的分布及阶段性区间。即使所有人都理性，风险补偿的变化也可以造成该区间迁移。

[已观察事实｜B] Campbell与Shiller的现值模型把股息价格比同未来股利增长及折现率预期联系起来，不能只从高股息率推断价格偏低。[R1：NBER原论文摘要](https://www.nber.org/papers/w2100)

[已知限制｜C] 代码中的3.1%、3.3%、3.5%、4.0%、4.2%是已有配置参数，尚无证据证明它们就是市场投资者的真实要求区间；股息率也不等于要求总回报率。本文不重新估计这些阈值。

[已知限制｜C] “类债”只表示研究中的现金流特征类比；本股票策略没有债券到期按面值偿还本金的价值锚。上述贴现公式不给出确定回本时间或最低股价。

### 2.2 价格锚的价值：条件性均值回归与库存管理

[计算结果｜A] 策略使用`Y_t = Dhat_t / Pproxy_t`，其中`Pproxy_t`是14:57后首个合格Tick代理价；给定要求股息率`y`，锚为`A_t(y) = Dhat_t / y`。

[研究假设｜C] 在`Dhat_t`可靠、要求股息率没有永久迁移的阶段，暂时资金流、风险偏好或流动性冲击可能把价格推离这个锚，并在之后部分修复。以下只是假设的形式化表达：

```text
x_t = log(Pproxy_t / A_t(y_ref))
E[x_(t+h) - x_t | 当时信息、预先定义的稳定状态] = -lambda_h x_t
lambda_h > 0 才与该期限的条件性修复假设一致
```

[方法选择｜C] `y_ref`和期限`h`这里只是理论符号；如阶段3登记该诊断，须事前固定选择和实验数量。不能在多个锚、期限和市场分类中搜索后只报告显著组合。

[已知限制｜C] “股息率回到原值”可能由股价回升实现，也可能由分红预期下调实现，后者未必使投资者获利。须同时观察`P`、`Dhat`和含分红净收益，不能只检验比率的平稳性。

[研究假设｜C] 另一条路径是库存管理：即使价格没有围绕常数均值波动，高估阶段减仓也可能降低下行风险。但相对于风险匹配静态持有是否仍有价值，要看何时减少暴露，不能仅看现金变多后回撤变小。

[计算结果｜A] 在无现金流错位、忽略执行摩擦的简化一期模型中，令`w_t`为持有期间开始前确定的股票权重，`r^TR`为含分红股票收益，`r^cash`为现金收益。相对比较权重`b_t`，收益差近似为：

```text
Delta r_(t+1) ≈ (w_t - b_t)(r^TR_(t+1) - r^cash_(t+1)) - Delta cost_(t+1)
```

[计算结果｜A] 若仅用常数`b`帮助解释，并取总体均值，则成本前期望差可分为`(E[w]-b)E[r^excess] + Cov(w,r^excess)`。第一项反映平均暴露差，第二项才体现仓位与后续超额收益的配合；这不是本次对真实数据做出的估计。

[方法选择｜C] 主风险匹配基准须用开发/验证期可得信息事前确定构建规则；禁止按锁定测试集里动态策略实现的平均敞口事后设置一个“事前静态”基准。事后精确敞口匹配至多是明确标注的诊断。

[已知限制｜C] 静态股数持有的权重会随价格变化，上式中的常数`b`不直接等于1500股静态基准。正式归因必须按实际每日账户和实际权重计算。

### 2.3 分红稳定性：必要的近似条件，但不是收益保证

[已观察事实｜A] Brav等对管理层的调查发现分红平滑及避免削减的倾向；论文同时讨论投资与流动性需求对派息的约束。这为分红粘性的可能性提供文献依据。[R2：原论文摘要及第4节](https://www.nber.org/papers/w9657.pdf)

[已知限制｜C] 该文献研究其他市场及历史时期，不能证明600900.SH的未来分红稳定，更不能证明1元分红可覆盖任何历史年度。

[研究假设｜C] 本策略需要的是：分红估计在一次库存调整及持有期限内足够可信，或其变化能被当时信息及时记录。必要条件并非分红永久不变，而是锚的误差与更新滞后不能系统性吞掉调仓收益。

[方法选择｜C] 后续按公告可得时间记录持续经营现金流、资本开支、融资负担、可分配利润、派息政策及估计修订。不能仅因最终没有削减分红，就事后把此前所有交易日分类为“基本面稳定”。

[已观察事实｜B] 当前规格记录分红值仍为静态占位、空`as_of`使过期检查失效、静态分红开关没有执行门禁；理论上的可信分红条件尚未由当前实现保证。

### 2.4 股价下跌的两种解释与移动的锚

[计算结果｜A] 对`A=Dhat/y`取对数有`Delta log A = Delta log Dhat - Delta log y`。因此分红下调和要求股息率上升都会使锚下移。

[方法选择｜C] 以下金额与股息率均为人为设定的教学输入，不是公司数据或历史回测；计算命令保存在第4节。

| [方法选择] 教学情形 | [计算结果｜A] 价格锚 | [计算结果｜A] 相对基础锚变化 |
|---|---:|---:|
| `Dhat=1`，要求股息率3.5% | 28.571429元 | 0% |
| `Dhat=1`，要求股息率升至4.0% | 25.000000元 | -12.5% |
| `Dhat=0.8`，要求股息率仍3.5% | 22.857143元 | -20.0% |
| `Dhat=0.8`，要求股息率升至4.0% | 20.000000元 | -30.0% |

[计算结果｜A] 另设价格由30元跌到24元：若仍用1元分红，显示股息率从3.3333%升至4.1667%；若可得分红估计已降至0.8元，股息率仍是3.3333%。看似变便宜可能只是分子未更新。

[研究假设｜C] 在稳定现金流且冲击暂时的情形，低价加仓可能捕捉修复；在盈利恶化、资本开支增加、派息削减或贴现率持续上升时，同一动作可能增加损失。

[方法选择｜C] 利率变化先作为固定阈值的失效解释和压力维度；这一轮不把固定股息率改成与国债收益率联动的策略。

### 2.5 滞回与分步：减少往返的条件和代价

[已观察事实｜A] 1100→1200股买入用3.5%，1200→1100股卖出用3.3%。在`Dhat=1`下，两个价格边界分别为28.571429元和30.303030元，中间有持有区间。

[计算结果｜A] 这组往返边界价差为`1/0.033 - 1/0.035 = 1.731602`元。一次加仓后，价格只在买入边界附近小幅抖动，并不会立即满足反向卖出边界。

[研究假设｜C] 因此，相比同一买卖边界的特定局部噪声路径，滞回可能减少反复交易；它不能保证对所有价格路径都降低总交易次数，更不能保证净收益上升。宽区间会延后卖出，分步交易会延后获得或解除风险暴露，两次确认也可能错过短暂机会。

[已观察事实｜A] Gârleanu与Pedersen在包含可预测收益与交易成本的模型中推导了部分调整的交易原则。[R3：作者原论文，摘要及引言](https://pages.stern.nyu.edu/~lpederse/papers/DynamicTrading.pdf)

[已知限制｜C] 该模型不能证明本策略的100股步长、两次确认或当前离散阈值最优；本策略的最低佣金、A股交易约束和人工闸门也不能直接套用论文模型。

[计算结果｜A] 教学往返设买入100股×28.5元，卖出100股×30.5元，毛价差200元。仅按章程的佣金万一、最低5元及卖出印花税万五假设计入，佣金合计10元、印花税1.525元，剩188.475元。该金额尚未扣滑点、其他费用和资金机会成本，不是完整净收益。

[已知限制｜C] 正价差只有在卖出实际完成后才实现。只统计完成的正收益往返，会漏掉仍在浮亏的库存和上涨时被卖掉的股票；未完成交易必须按共同期末市价估值，不能删掉。

### 2.6 单边上涨：减仓机会损失

[计算结果｜A] 若卖出`q`股于`F_s`后始终未买回，截至共同终点`T`相对继续持有这批股票的机会损失为：

```text
Loss_opportunity = q(P_T - F_s)
                   + 继续持有该批股票本可取得的分红权益
                   - 卖出所得现金在该期间的收益
                   + 该次卖出及相关动作的额外成本
```

[计算结果｜A] 简化为没有分红、现金收益和费用时，100股在30元卖出、终点35元，少赚500元，即使卖出时相对买入成本是盈利的。若中途买回，要按分段持仓差重新归因，不能一直累计至终点。

[研究假设｜C] 持续上涨或要求股息率持续下降时，策略可能较早降至核心仓并长期落后静态持有。两次确认可能推迟这种损失，也可能只改变损失发生时间。

### 2.7 持续下跌：库存堆积与个人风险约束

[研究假设｜C] 当`Dhat`下调滞后或基本面闸门反应滞后，价格越跌、机械股息率越高，正常路径可逐步增至1400股。核心仓保护限制普通卖出，所以达到仓位上限后仍可能继续承受损失。

[计算结果｜A] 仅用核心仓即可构造违反16%护栏的教学例子：期初资产60,000元，持1000股、价格30元、现金30,000元；价格跌至20元且期间无其他现金流时，资产为50,000元，回撤16.6667%。

[已知限制｜C] 因此核心仓保护、加仓上限和停止加仓都不保证最大回撤≤16%，也不保证6个月修复。16%与6个月是个人验收约束；未来违约时须如实判定个人适配性，而不能由本阶段擅自加止损规则。

[已观察事实｜B] 当前规格中的亏损停止加仓量是本标的未实现损失占当前总资产比例，和账户高水位回撤不同；`EXIT`又受更前面的数据有效性检查影响。这些实现条件会决定理论闸门是否真正能限制库存风险。

### 2.8 同日收盘集合竞价：理论收益如何到达账户

[方法选择｜C] 主研究时间线如下，所有信息必须在决策时已经可得：

```text
t-1正式收盘 + available_time≤decision_time的Dhat_t
    → t日14:57:00后首个合格Tick，冻结Pproxy_t
    → 两个价格确认、相邻状态决策、风控
    → t日15:00前提交限价委托
    → 交易所撮合/未成交/部分成交
    → 按真实回报或预注册撮合模型记账
```

[已观察事实｜A] 上交所官方说明记载股票收盘集合竞价自2018-08-20实施。[R4：历史制度公告](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20180806_4607055.shtml)

[方法选择｜C] 同一主执行机制的历史样本不得早于2018-08-20；实际起点还须取决于PIT分红和竞价数据的共同覆盖。更早日线可留作背景或另列机械研究，不能假称当时存在该收盘交易机制。

[已观察事实｜A] 现行上交所2026版规则的官方页面载明2026-07-06生效；检索到的规则文本区分集合竞价虚拟参考价格和最终集中撮合成交价格。[R5：官方交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)

[已观察事实｜B] 迅投文档检索结果将Tick的`lastPrice`标为“最新价”。[R6：迅投字段说明](https://dict.thinktrader.net/dictionary/stock.html)

[已知限制｜C] 现有证据不足以确定本地接口在14:57竞价阶段的`lastPrice`是否对应虚拟参考价、此前最新成交价或其他供应商处理值。快照时间新鲜不等于价格发生了新的成交；字段映射须用接口版本说明与实际快照核验。

[方法选择｜C] 保持已确认的`lastPrice`代理信号规则；阶段4记录字段语义及真实抓取时刻，不把14:57整点、14:57后首个收到的Tick和15:00最终价混用。查清映射前不改成其他价格字段。

[已观察事实｜A] 核心确认函数会把最近两个有效价格同当前计算的触发价比较。因此若`Dhat_t`刚修订，前一正式收盘也会按当前锚判断；这不是“昨日使用昨日分红估计已确认买入”的同义表达。当前可得分红对旧价重估本身不构成未来信息，但两种确认定义不得混写。

[方法选择｜C] L2/L3可在具有必要市场数据后采用事前声明的保守撮合模型，生成模拟委托与成交流水，不要求历史上存在本账户实际下单。历史真实订单缺失限制的是成交假设验证；L4再用仿真/真实观察回报验证可执行性。真实交易仍须另获授权。

[研究假设｜C] 令方向`side=+1`为买、`-1`为卖，代理价到成交价的不利偏移定义为`side×(F_t-Pproxy_t)`。若该偏移、未成交和费用足以吞掉库存调整收益，则规则能产生好信号也不能推出可执行净增量。

## 3. 本阶段实际操作：因果链、替代解释与判别预测

### 3.1 待检验的机制图

[研究假设｜C] 下列每个箭头都是待检验关系，图中并未证明市场参与者的偏好或行为：

```text
分红能力相对稳定 + 时点估计可靠
    → 投资者可能存在阶段性的股息率要求区间
    → 价格偏离含有后续收益/风险信息
    → 股息率、实际持仓与闸门共同改变目标库存
    → 滞回、确认及分步可能减少噪声交易
    → 可执行成交与完整现金流记账
    → 相对风险匹配静态持有可能产生样本外净增量

利率/风险溢价/长期增长 ──→ 要求区间、价格、后续回报
盈利/资本开支/派息政策 ──→ 分红能力、预期、闸门、价格
趋势/风格/流动性冲击 ──→ 价格、成交条件、策略和基准收益
除息/税费/数据时点错误 ──→ 测量股息率、信号、账面收益
```

[已知限制｜C] 同一股价路径上的可复现策略对照可以评估既定规则在该路径的条件表现，但不能单独识别“投资者因股息率要求而买卖”的市场因果机制。单标的事件前后比较和收益预测回归仍可能受混杂因素影响。

### 3.2 支持链条的预测及其反证

[方法选择｜C] 下表的M编号是机制诊断标签，不是新增候选策略或已经批准执行的实验。未来只纳入阶段3明确登记的诊断，并将失败结果一并记录。

| 机制诊断 | [研究假设｜C] 若机制成立，预期观察到什么 | [研究假设｜C] 什么会削弱该解释 | [方法选择｜C] 后续可用证据 |
|---|---|---|---|
| M1 分红锚可靠 | 当时估计与后续可得修订不存在频繁、单向、重大的高估 | 加仓后屡次下调分红，所谓高收益率由滞后分子制造 | 公告时间、估计版本、修订事件和未完成库存 |
| M2 条件价格修复 | 预先定义的稳定状态内，买入信号后含分红回报及相对收益更有利 | 比率修复主要由Dhat下降实现；风险匹配后不再有利 | 联合分解价格、分红预期、利率和后续收益 |
| M3 库存择时价值 | 平均风险可比后净增量仍跨窗口出现 | 优势可被相近静态股票/现金配置解释 | 事前风险匹配、每日暴露和账户净增量 |
| M4 滞回成本价值 | 局部噪声往返减少，节省的成本超过延迟机会损失 | 少交易却错过主要修复，或成本放大后增量消失 | 同路径规则诊断；若做去滞回消融，须另行预注册 |
| M5 上涨机会成本可承受 | 多个市场状态合计增量能覆盖上涨减仓损失 | 少数震荡期盈利被趋势期少赚抵消 | 全部持仓差的机会损失和年度贡献 |
| M6 下跌库存风险可承受 | 回撤、修复期、库存占用符合预注册护栏 | 持续跌价下高仓位长期滞留，触及个人护栏 | 期末未完成库存、峰值暴露、未修复回撤 |
| M7 执行后优势保留 | 真实字段、信息时点和保守撮合下仍有增量 | 只有把15:00价用于14:57信号或按代理价无摩擦成交才有效 | Tick与接收时间、决策日志、委托/成交/拒绝流水 |

[已知限制｜C] M1—M7缺乏足够有效事件时结论应是证据不足，不能把“未显著拒绝”当成支持。机制诊断通过也不能替代唯一首要指标；一次压力失败是否淘汰由阶段3的预注册规则决定。

### 3.3 替代解释和混杂因素清单

| 因素 | [研究假设｜C] 可能产生的替代解释 | [方法选择｜C] 计划判别与限制 |
|---|---|---|
| 利率变化 | 要求收益率永久上移/下移，固定锚跟不上 | 用当时可得利率分层或作有限诊断；首轮不改交易阈值 |
| 盈利和分红政策 | 股价先反映坏消息，滞后Dhat造成虚假低估 | 逐条登记公告、政策修订与可得时间；禁止用最终结果回填 |
| 市场风格 | 红利偏好变化驱动估值重估，策略只是风格暴露 | 预注册风格/市场控制；同一股票静态基准仍须匹配风险 |
| 大盘趋势 | 牛熊市决定大部分收益；减仓看似择时实为现金保护 | 跨时段对照、滚动样本外及贡献集中度，不只看全期收益 |
| 监管和税制 | 派息激励、交易限制和成本变迁改变可投资收益 | 历史生效日版本化；不得用2026规则覆盖全历史 |
| 除权除息 | 未复权价格下跳提高股息率，同时股东获得分红权利 | 按登记日确定权益，派息日增加可用现金；比较策略与基准一致处理 |
| 股价长期趋势 | 固定阈值只在少数年份活跃，剩余时间变成静态持仓 | 统计独立状态转换及未完成库存，不以日线行数替代事件数 |
| 未来分红信息 | 先知道最终分红，锚和闸门获得不可实现的优势 | 逐条验证available_time，保留修订旧版，延迟敏感性 |
| 现金和初始化 | 1000/1200/0股不同暴露或早期建仓成本主导结果 | 同资金分开报告，固定成本基准日；不得择优起点 |
| 人工基本面闸门 | 事后选择EXIT日，收益来自研究者事后择时 | 只用有时间戳的历史判断或预先确定的可复现映射；缺失记限制 |
| 个股选择与参数历史 | 因已知过去表现而选中公司/档位，外推被高估 | 登记策略选择历史，冻结后保留测试集；不宣称回溯预注册 |
| 成交样本选择 | 只分析已成交或盈利往返，遗漏未成交和浮亏 | 记录所有信号、订单状态及终端估值，禁止删掉失败交易 |

[方法选择｜C] 除息日至到账日之间的股息权益应在阶段4明确估值：可记录应收股息但不能作为可交易现金。若只在到账日纳入资产，要披露期间测量回撤的影响；不得把除息落价与收益消失等同，也不能同时算复权总收益和现金分红。

[已知限制｜C] 没有历史闸门记录时，“全期NORMAL”只能定义为缺少基本面防护的条件性规则实验；它不能支持包含人工保护的完整策略有效性。该口径须阶段3/4明确，不在本阶段补造闸门。

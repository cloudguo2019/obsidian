### 2.1 符号定义

| [已观察事实｜A] `D`           | v1.4.2配置中的 `expected_annual_dividend_per_share`；当前值为1.0元/股，并非历史时点序列 |

- [已观察事实｜A] 原始档位按最低股息率从高到低匹配，首个满足 `Y_t >= min_yield` 的档位生效。

| [计算结果｜A] buy_zone | `4.0% <= Y < 4.2%` | `23.8095 < P <= 25.0000` | 1400 |
| [计算结果｜A] neutral | `3.5% <= Y < 4.0%` | `25.0000 < P <= 28.5714` | 1300 |

### 2.3 相邻状态滞回

- [已观察事实｜A] 对相邻状态 `(Q_L,Q_U)`，低仓状态买入使用更高一档的股息率阈值，高仓状态卖出使用较低一档的股息率阈值，由此形成非重合的买卖边界。
- [计算结果｜A] 买入条件为 `Y_t >= Y_buy`，等价于 `P_t <= D/Y_buy`；卖出条件为 `Y_t <= Y_sell`，等价于 `P_t >= D/Y_sell`。
- [计算结果｜A] 因为 `Y_buy > Y_sell`，同一相邻状态对之间存在 `D/Y_buy < P < D/Y_sell` 的持有区间。

| 相邻状态 | 低仓买入边界 | `D=1`买入价 | 高仓卖出边界 | `D=1`卖出价 |
|---|---:|---:|---:|---:|
| [计算结果｜A] 1000 ↔ 1100 | `Y >= 3.3%` | `P <= 30.3030` | `Y <= 3.1%` | `P >= 32.2581` |
| [计算结果｜A] 1100 ↔ 1200 | `Y >= 3.5%` | `P <= 28.5714` | `Y <= 3.3%` | `P >= 30.3030` |
| [计算结果｜A] 1200 ↔ 1300 | `Y >= 4.0%` | `P <= 25.0000` | `Y <= 3.5%` | `P >= 28.5714` |
| [计算结果｜A] 1300 ↔ 1400 | `Y >= 4.2%` | `P <= 23.8095` | `Y <= 4.0%` | `P >= 25.0000` |
| [计算结果｜A] 1400 ↔ 1500 | 自动买入禁用 | 禁用 | `Y <= 4.2%` | `P >= 23.8095` |

- [已观察事实｜A] 上表边界在代码中是包含等号的；买入使用 `<= trigger_price`，卖出使用 `>= trigger_price`。
- [已观察事实｜B] v1.4.2测试源码覆盖边界等号；本次已读取测试源码，但因本机运行时缺少`pytest`而未复跑。

| 当前实际持仓 `Q_t` | 经确认后的价格动作 | 相邻下一状态 `Q_next` | 持有条件 |
|---:|---|---:|---|
| [已观察事实｜A] 0、100、…、900 | 与估值无关，尝试增加100股 | `min(Q_t+100,1000)` | 数据确认未就绪、`manage_existing_only`在0股时启用、买入闸门或下游风控阻止时持有 |

| [计算结果｜A] 1100 | 两次确认 `P <= 28.5714` 买入；`P >= 32.2581` 卖出 | 1200或1000 | `28.5714 < P < 32.2581` 持有 |
| [计算结果｜A] 1200 | 两次确认 `P <= 25.0000` 买入；`P >= 30.3030` 卖出 | 1300或1100 | `25.0000 < P < 30.3030` 持有 |
| [计算结果｜A] 1300 | 两次确认 `P <= 23.8095` 买入；`P >= 28.5714` 卖出 | 1400或1200 | `23.8095 < P < 28.5714` 持有 |

### 2.5 两类确认语义

#### 日线/机械路径

- [已观察事实｜A] `confirmation_bars=2` 时，买入要求最近两根有效bar收盘价都不高于买入锚；卖出要求最近两根有效bar收盘价都不低于卖出锚。
- [已观察事实｜A] 日线回测调用 `generate_signal(..., drop_last_bar=False)`，因此最近两个价格包括当前已完成交易日的收盘价；当前配置`backtest.period="1d"`。
- [已观察事实｜A] 空仓或低于核心仓的逐步建仓只检查是否已有至少两根有效bar，不检查这些价格是否处于任何买入区间。

#### 收盘集合竞价执行适配器（代码路径）

- [已观察事实｜A] 管线严格限定在`[14:57:00,15:00:00)`；14:57前不生成候选，15:00起不再生成或提交新委托。
- [已观察事实｜A] 适配器强制刷新Tick，只接受当日、时间不早于14:57、默认年龄不超过5秒、`stockStatus=18`、证券未停牌且`lastPrice`有效的行情。
- [已观察事实｜A] 首个合格Tick的`lastPrice`被冻结为代理收盘价，并在内存中构造成`is_synthetic=true`、`is_proxy_daily_bar=true`、`bar_type=proxy_daily_bar`、`source=closing_auction_tick_14_57`的代理日K；它不写入正式K线库。
- [已观察事实｜A] `confirmation_bars=2`时，确认数据为“前一交易日正式收盘 + 当日单个代理收盘价”；旧近似收盘管线的30秒样本数、80%比例和窗口中位数均不参与当前`closing_auction`判断。
- [已观察事实｜A] 买入以涨停价、卖出以跌停价作为`FIX_PRICE`委托价和最坏情形风控价格；涨跌停价优先来自证券详情，仅`600900.SH`在接口缺失时允许按昨收±10%回退，其他标的缺失权威涨跌停价则失败关闭。
- [已观察事实｜A] 委托策略是`single_submit`：每标的每日最多一次，不等待、不撤单、不改价、不重试；模拟环境保留涨跌停委托价，但以冻结代理收盘价记模拟成交。
- [已观察事实｜A] 16:00起刷新当日真实日K，最晚重试至16:30；真实日K只供后续交易日使用，不重算也不补发当日竞价委托。

### 2.6 基本面闸门和账户亏损停止加仓

| 闸门 | 真实代码行为 |
|---|---|
| [已观察事实｜A] `NORMAL` | 允许正常状态机动作，仍受分红有效期、账户亏损、核心保护、可卖数量和下游风控约束 |
| [已观察事实｜A] `REVIEW` | 阻止估值买入和卖出，直接返回持有 |
| [已观察事实｜A] `STOP_ADD` | 阻止所有增加持仓，包括从0至1000的核心仓建立；允许估值减仓和超限减仓 |
| [已观察事实｜A] `EXIT` | 若当前持仓高于 `fundamental_exit_target_volume`，直接产生该绝对目标的卖出信号；不受100股单步和核心仓保护限制，也不要求两日/两时点价格确认 |

- [计算结果｜A] 账户亏损影响定义为：

```text
loss_impact_t = min((P_t - avg_price_t) × Q_t, 0) / total_asset_t
```

- [已观察事实｜A] 当 `loss_impact_t <= -10%` 时，策略阻止增加持仓；它不主动卖出，也不阻止满足条件的估值卖出。
- [已观察事实｜A] 该量只衡量本标的按平均持仓成本计算的未实现负损益占当前总资产的比例，不是完整账户回撤。
- [已观察事实｜A] `price_drawdown_watch=-15%` 和 `price_drawdown_deep_watch=-20%` 只写入 `risk_hint`，不会自动阻止买入或强制卖出。

### 2.7 分红估计过期规则

- [计算结果｜A] 当 `dividend_estimate_as_of` 能解析成日期且 `valid_days>0` 时，仅当 `run_date - as_of > valid_days` 才判为过期；恰好等于180个自然日仍有效。
- [已观察事实｜A] `dividend_estimate_as_of` 为空或无法解析时，函数直接返回“不陈旧”。
- [已观察事实｜A] `dividend_estimate_valid_days<=0` 时，过期检查同样被关闭。
- [已观察事实｜A] v1.4.2配置的 `dividend_estimate_as_of=""`，所以180天有效期在当前配置中实际失效。
- [已观察事实｜A] 如果运行日期无法解析，代码会回退到机器当天日期；这会降低同一输入在不同运行日的可复现性。

## 3. 本阶段实际操作与核验结果

### 3.1 决策优先级

- [已观察事实｜A] v1.4.2核心策略大致按以下优先级处理单个标的：

```text
字段/数据帧/价格有效性
→ 当日重复bar去重
→ 分红值有效性
→ 分红估计过期检查
→ 总资产有效性
→ REVIEW / EXIT 基本面闸门
→ 实际持仓状态识别与确认
→ 相邻状态决策
→ 100股单步夹紧
→ STOP_ADD / loss_impact 买入阻断
→ 当日同方向信号去重
→ 核心仓与可卖数量检查
→ 输出目标仓位信号
→ 下游通用风控、委托与成交
```

- [已观察事实｜A] `EXIT` 位于分红过期检查和总资产检查之后，因此分红过期、分红无效或总资产无效会先返回持有，阻止基本面退出信号。

|---|---|---|

| 超限纠偏依赖实际成交 | [已观察事实｜A] | 超限仓位按每次100股逐步指向1500；例如1550的目标是1500，不会先被错误地写成1450，未成交期间仍可能高于1500 |

| 日线与竞价语义错配 | [已观察事实｜A] | 日线信号用当日完整收盘并在下一交易日开盘成交，无法证明当日14:57集合竞价可执行性 |

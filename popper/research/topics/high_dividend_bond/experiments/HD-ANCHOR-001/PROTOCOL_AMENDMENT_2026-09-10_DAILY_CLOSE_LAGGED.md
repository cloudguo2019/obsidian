## 1. 为什么不能“用T日收盘价发出T日收盘竞价委托”

[已观察事实｜A] 上交所现行《上海证券交易所交易规则（2026年修订）》规定，股票14:57—15:00为收盘集合竞价；该阶段即时行情揭示集合竞价虚拟参考价格、虚拟匹配量和虚拟未匹配量。规则于2026-07-06生效。[上交所规则原文](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)（检索日期：2026-09-10）。

[已观察事实｜A] 上交所2018年收盘交易机制调整公告已明确股票自2018-08-20起采用14:57—15:00三分钟收盘集合竞价；本研究预注册的机制下界为2018-08-20，故该时序规则覆盖计划研究期。[上交所2018年公告](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20180806_4607055.shtml)（检索日期：2026-09-10）。

[方法选择｜C] 因此，T日最终`close_t`只能在T日收盘集合竞价撮合完成后作为一根“已完成日K”使用。若模型用`close_t`判断信号、又声明在同一T日以`close_t`成交，就会在决策时使用尚未确定的成交结果，构成信号—成交错位。

[方法选择｜C] v1.1采用最小的一日滞后：T日收盘后以`close_t`形成信号；在T+1日14:57后提交已由T日信息决定的委托；以T+1日最终收盘集合竞价价`close_t+1`作为成交价。该延迟是对原v1.0“14:57 Tick信号、同日收盘竞价成交”执行模型的保守替代，不改股息率阈值、仓位、确认数、NORMAL_ONLY范围、基准、指标或统计门槛。

## 2. v1.1主执行模型：`DAILY_CLOSE_LAGGED_AUCTION_V1`

| 环节 | 冻结定义 |
|---|---|
| [方法选择｜C] 决策数据 | T日已完成的未复权官方日线收盘价`close_t`；分红估计只可使用`available_time <= T日15:00:00+08:00`的最新有效记录 |
| [方法选择｜C] 信号时点 | T日收盘集合竞价完成后；只在日线数据作为已完成日K可用后计算 |
| [方法选择｜C] 两日确认 | 仅使用连续两个已完成日K的信号状态；不得使用T+1日开盘、最高、最低或收盘信息确认T日信号 |
| [方法选择｜C] 委托时点 | T+1日14:57后在收盘集合竞价阶段提交一次；历史回放不声称已知精确报单毫秒 |
| [方法选择｜C] 成交时点/价格 | T+1日15:00收盘集合竞价；按权威未复权`close_t+1`入账 |
| [方法选择｜C] 成交假设 | 继承P00的有效保护限价、当日可交易且有有效最终收盘价时假设全额成交；不使用竞价量参与率门槛，不另加固定bp摩擦 |
| [方法选择｜C] 失败委托 | T+1缺失价格、停牌、无有效收盘价、资金/可卖股不足、价格限制或委托无效时，记录`UNFILLED`；不延后补单 |

```text
T日15:00后：已完成 close_t + 当时有效 Dhat_t
          → 两日确认与目标仓位
          → 生成仅一次、不可事后改价的T+1收盘竞价委托

T+1日14:57：提交原目标的保护限价委托
T+1日15:00：以权威 close_t+1 记为成交价，或记录UNFILLED
```

[方法选择｜C] `close_t+1`只作为已经提交委托后的实现成交价格，绝不参与T日信号、目标仓位、是否报单或报单限价选择。

[已知限制｜C] 没有历史逐笔委托与队列数据时，“按保护限价全额成交”仍是研究成交假设，不是实际成交率证据；P22/P23和未来L4继续检验该假设。

## 3. 对原协议的精确覆盖

| 原v1.0字段/规则 | v1.1覆盖后定义 |
|---|---|
| [方法选择｜C] `confirmed_context.execution` | `T日已完成未复权日线收盘价形成信号，T+1日收盘集合竞价提交并按T+1日最终收盘价回放成交。` |
| [方法选择｜C] `execution_and_costs.signal_tick` | P00不再使用；历史14:57 Tick只保留给L4执行审计和未来`HD-EXEC-002`，不再是P00的L2门禁 |
| [方法选择｜C] `auction_fill_model` | 保留保护限价、全额成交、零固定bp摩擦与现实费用；成交日从T日改为T+1日 |
| [方法选择｜C] `P03` | T日信号再延迟1个完整决策日，于T+2日收盘竞价成交 |
| [方法选择｜C] `P04` | T日信号再延迟2个完整决策日，于T+3日收盘竞价成交 |
| [方法选择｜C] `P05` | T日已完成日K信号，于T+1日开盘集合竞价成交；作为不同时间段的已登记压力测试 |
| [方法选择｜C] L1日线对照 | 可运行“固定分红假设机械回测：日线收盘信号至下一交易日收盘竞价”；不得把它写成L2投资有效性结论 |
| [方法选择｜C] L2执行门禁 | 不再要求多年14:57 Tick；仍要求PIT分红、真实公司行动、未复权日线、交易状态/价格限制、权威交易日历、历史税费表、数据版本与逐日账户对账 |

[方法选择｜C] 延迟队列保持原绝对目标仓位，T+1只允许因现金、可卖股、停牌、价格限制或订单无效而裁剪或拒绝；不得使用T+1的股息率、价格、收益或最终成交量重新选择目标。

[方法选择｜C] T+1日成交完成后，才以T+1已完成日K及成交后的实际持仓生成下一条可能在T+2日执行的指令。这样避免同一时刻存在互相覆盖的日线信号订单。

## 5. 冻结与解释边界

[方法选择｜C] 新版本标识为`1.1-daily-close-lagged-methods-frozen`。它仅回答“日线收盘信号、延后一日收盘竞价成交”的策略是否相对静态持有有增量；不再直接检验原v1.0的同日14:57执行优势。

[已知限制｜C] 若v1.1通过，结论不能倒推为“14:57同日竞价策略已通过”；若v1.1不通过，也不能单独证明原14:57 Tick执行版本无效，因为两者存在一日执行延迟差异。

[方法选择｜C] 后续正式报告必须同时列示v1.0未运行、v1.1运行与其执行差异；不得把v1.1结果改名为原始`HD-ANCHOR-001`同日竞价结果。
